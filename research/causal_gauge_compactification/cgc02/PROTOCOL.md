## Actual physical recurrent model and protected readout

State dimension d=12, shared nonlinear feature width 32, event input dimension 4. At time 0 the complete state contains an independently sampled public scalar p at coordinates 0 and 4 (p, -0.2p); all other coordinates are zero. The one-time private source-write event is x=(a,b,r,1), with a,b,p iid Uniform[-0.8,0.8] on training, and r uniform in {-1,+1}. The **same** physical weight-tied transition executes for source write and every subsequent no-op recurrent pass:

\[
F_\theta(h,x)=h+\tanh(hA+xB+b_0)C,\ 
A\in\mathbb R^{12\times32}, B\in\mathbb R^{4\times32}, C\in\mathbb R^{32\times12}.
\]

All post-write recurrences receive x=0. There is no extra KV cache, hidden scheduler or separate physical recurrence per depth.

The actual current protected output is the **full three-class normalized probability vector**
\[
P(h)=\operatorname{softmax}(h_0,h_4,0).
\]
The exact affine protected-fiber kernel used for causal edits is
\(K=\{\delta:\delta_0=\delta_4=0\}\), dimension 10. Every proposed intervention is checked against the **complete normalized** protected readout before continuation, with max component error ≤1e-6. This is a sufficiently conservative kernel inside DP's true softmax kernel (which may admit extra common-logit gauge directions); it is an explicitly declared **subkernel**, not a claimed complete characterization of ker DP.

The independent ground-truth task at after-write depth k is two scalars
\[
Y^*(a,b,r)=\left(a\mathbf1_{r=1}+b\mathbf1_{r=-1},\
\tfrac12(a+b)+0.2ab\right),
\]
decoded by the **fixed** last two state coordinates after k shared no-op updates. Targets are independently computed from the input generator, not generated by the teacher.

Teacher training: Adam learning rate 0.008, **650 updates**, batch 128, PyTorch CPU one thread. At depths k=2,4,6 use weighted scalar-output MSE with weights (0.75,1.0,0.5), plus 0.025 per visited step on the squared change of the two public carrier state coordinates relative to their initial values; L2 weight objective 1e-4. This is supervised recurrence at declared depths, with **depth 8 never used for teacher training or calibration rank selection**.

## Development-only task subspace selection

Using **256 independent training-family source examples per teacher root**, freeze two *rank-two* physical hidden-state subspaces after the one source-write step. For k=2,4,6, compute both true task-output Jacobian rows \(\partial T_k(h_1)/\partial h_1\) through the frozen recurrent transition; restrict these derivatives to K. Define
\[
G_k=\tfrac1{256}\sum_i J_{i,k,K}^{\top}J_{i,k,K}.
\]
The first task block \(E_4\) uses the top-two eigenspace of G_4. The multi-depth task block \(E_\mathrm{multi}\) uses the top two eigendirections of \(0.75G_2+G_4+0.5G_6\). Also freeze the top-two **physical output-weight SVD** subspaces of BPD factor fit 1 and of teacher C, each orthogonally projected into K and reorthonormalized. Include one fixed seeded rank-two **random protected subspace** and full protected-write and exact donor-dark controls. The preferred rank-two block is fixed by this procedure, not chosen using heldout causal outcomes.

Record singular/eigenvalue gaps at the second/third directions. A small gap renders subspace identity unstable; top-two projectors are compared, not unordered singular-vector signs. No component singleton, alignment oracle or heldout rank search is admitted as a discovered BPD mechanism.

## Independent heldout source-pair assay

For each root generate exactly **512** independent evaluation pairs from an anti-correlated scalar source family:
a~U[-0.8,0.8], b=clip(-0.8a+0.2 N(0,1), ±0.8), p independent, r uniform ±1. The donor changes **only the queried source value** a or b by signed magnitude in [0.30,0.65], clamped to ±0.8. The public scalar, role and other source value remain identical; ground-truth donor Y* is recomputed from the true scalars. Both recipient and donor states share the same initial h0; only their event source inputs differ.

Declare the eligibility gate once, using *clean* teacher states:
- both recipient and donor depth-4 two-dimensional task outputs within ±0.08 per coordinate of their separately defined exact ground-truth target;
- clean donor/recipient depth-4 task-output max-coordinate difference ≥0.15;
- complete current protected three-class softmax readout max discrepancy after source-write step ≤0.02.

All 512 generated pairs, clean-error counts, protected mismatch and eligible counts are retained. Denominators are independently generated pairs; the teacher root is the inferential unit. Do not replace failures or select only already successful intervention rows.

For each eligible pair form the BPD donor physical write \(\delta=(\phi(h_0,x_d)-\phi(h_0,x_r))\widehat C_1\), project its coordinates 0 and 4 to zero, and inject at the **post-write state h1_r** before future recurrence. Rank-two edits use orthogonal projection of this physical write into the respective frozen physical subspaces. Compare true teacher-C physical write, exact current-dark donor-state difference, full physical BPD write, zero edit, and physical SVD baseline. Assert *actual normalized protected-readout equality* for every proposed intervention before continuation.

Each root is evaluated at post-write depths **2,4,6,8**. The depth-8 task output is a **new recurrent-depth extrapolation** beyond teacher supervision and Gramian selection; it is scored only once after registration. Report teacher ground-truth MAE at every depth, donor-model relative MSE and ±0.10 donor recovery on eligible and all generated pairs, finite future protected softmax drift, intervention L2 dose and local one-step reduced-state closure defect. A small tangent task dimension is *not* an automatically closed dynamical quotient.

Use 32 independently seeded same-dose random K edits per root as a weak control at depth 8, and 16 **privileged** signed full two-task-Jacobian-and-norm matched K directions for the multi-depth task block at depths 4 and 8. The latter matches \(\|v\|_2\) and the *full signed* \(J_k v\) with an independent direction in \(\ker J_k\); report maximum numerical mismatch. These controls use target model gradients as an explicit high-information null and are **not** evidence of a deployable feature selector. Use identical donor eligibility, and keep matched controls *inside* the declared exact current-readout kernel.

## Frozen descriptive decision criteria

**Engineering gates**: 4 roots executed; teacher clean depth-4 MAE ≤0.08 and depth-8 MAE ≤0.15, physical factor MSE ≤1e-4 for both refits; actual current normalized protected readout mismatch ≤1e-6; complete BPD GL gauge error ≤2e-5; native mask and swap numerical errors ≤1e-5; no nonfinite values, and matched full-task tangent/norm error ≤1e-4.

**Exploratory rank-two portability gate**: in at least 3/4 roots with ≥200 eligible pairs, multi-depth task-block depth-8 donor MSE ≤0.8× physical-BPD-weight-SVD rank-two donor MSE, and donor recovery ≥0.10 above the 32 same-dose random-K control mean. Report depth-4 difference separately. **Stronger incremental mechanism gate**: in at least 3/4 roots, depth-8 multi-depth task-block recovery ≥0.05 above its **privileged signed full-task-Jacobian-and-norm matched** control mean. These are fixed descriptive criteria on four roots, **not** a 95/95 calibrated null or statistical proof.

A failed gate is a valid experimental result; do not tune architecture, seeds, rank, depth or thresholds after inspecting fresh results. The exact current readout has only three classes and no token positions; this synthetic model cannot establish real language-model transcript privacy. Full BPD reconstruction, protected task-SVD and a genuine compact independent reduced transition are different claims.
