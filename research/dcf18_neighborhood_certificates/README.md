# DCF-18: Exact neighborhood decision certificates

CPU exploratory pilot. Positive integer unary/pair factors on Boolean variables. Given a region R containing q, conditioning on its entire adjacent boundary separates R from the remaining graph. The marginal at q is a convex combination of conditional marginals over boundary assignments; their extrema bound it. Larger nested regions tighten (or preserve) bounds by the same mixture identity. Exact integer elimination and Fraction comparisons avoid rounding errors. The certificate is conditional on the supplied factor model; it does not validate the model itself. Boundary enumeration capped at 8 variables; fallback is unrestricted exact integer elimination on these fixtures. Reward +1/-4/0, tie convention act at p<=1/5 or p>=4/5. A certified abstention is Bayes-optimal abstention, not a budget failure.

Primary: 216 fresh cases, n=12/24/48, cycle/ladder/chords, 24 seeds per cell. Unary integers 2–9, pair entries 3–8. All available bounds contain the global rational posterior; 12 brute force independent checks at n12 agree exactly. All 648 policy decisions agree. Optimal actions: 195 abstain, 13 zero, 8 one. Cumulative radius0/1/2 certificate counts 117/207/214, actionable certificate counts 6/16/20. Of 25 cases within .05 of either threshold, 2/17/23 certified. Primary single-pass diagnostic timings are in receipt.json. Separate actual early-stop timing with one warmup and five randomized repetitions per arm yields mean of per-case medians (ms): global 1.362496, radius0 .612949, radius1 .416459, radius2 .444721; median paired speedup 2.855/3.936/3.949 respectively. Radius1 faster or equal in 167/216. Fixture generation and reference calculation excluded from timings; no cached plans or compiled backend. Abstention imbalance favors easy certificates.

Post-pilot stress: 108 fresh fixtures with same graph families, new seeds. Generator tunes query unary odds using global reference only, rational approximation denominator <=256, to target .195/.205/.795/.805 equally. Maximum target error 6.7062e-5. Inference sees only resulting factors and query. 54 optimal abstentions, 27 zero, 27 one. Every policy matches global decisions. Radius0/1/2 resolves 1/20/93 cases, including 0/16/48 actionable decisions. Mean median runtime global 1.341238 ms, radius0 1.407398, radius1 1.690464, radius2 1.858593. Radius2 faster/equal only 47/108. All certificate-first policies lose on mean latency here; no unconditional promotion. Stress set intentionally oracle-shaped, not representative of a naturally occurring distribution. No independent brute audit of all larger fixtures; global and conditional solvers share elimination implementation. No learned router, hardware, memory, or energy claims. No paid compute.

Reproduce with Python 3.13.5, NumPy 2.3.5: sha256sum -c PRE_RUN_SHA256; python benchmark.py; sha256sum -c TIMING_PRE_RUN_SHA256; python timing.py; sha256sum -c CHALLENGE_PRE_RUN_SHA256; python challenge.py. Timing receipts vary with hardware/load.
