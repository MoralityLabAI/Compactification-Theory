# SCM-17 protocol and evidence thresholds

**Registered:** November 14, 2026, before access to trained RMP artifacts or independent model results in this execution. SCM-16 is the comparator code; original RMP G0, source models, checkpoint hashes, sealed tests, and Phase 2 results remain untouched.

1. **Source checks:** require original C3 checkpoint plus `.receipt.json`, named RMP run `result.json`, six RMP source files, D-shared selection metrics, matching strict dictionary state dictionary and monitor bundle. Capture SHA-256 hashes, verify the RMP checkpoint receipt SHA-256/size, freeze an immutable manifest, and refuse absent or changed resources.
2. **Selection:** original `monitor_train` for adapter updates, 96 group-distinct examples balanced 24 per family; eight discovery frame cases from selection-half `monitor_calibration`; 64 reporting-half calibration examples as existing exploratory readout. No final sealed test calls. The selected margins are clean top-logit contrasts, never gold-selected.
3. **Model:** freeze the original `LOOP-T s1` or `FF-U s3` cell and the fixed D-shared SAE; retain its eight visits and per-cell input-reinjection settings. Fit a rank-at-most-eight decision frame from up to two clean runner-up margins per discovery task, requiring at least 75% captured gradient energy. Train a rank-eight shared VPD with visit gates for 60 optimizer steps, batch size 12, learning rate .002, and a 0.01 squared-correction penalty.
4. **Controls:** tied checkpoint, joint VPD, visible-only VPD, fiber-only VPD, reversed visit order, and zero-SAE codes. Each arm uses the same source checkpoint and selected examples. Report exact match, cross entropy, model forward visits, wall time if available, and trained parameters. Evaluation is deterministic and runs after fitting.
5. **Mechanism:** an independent symmetric fiber perturbation at each visit on one discovery task, at amplitude 0.01 in residual units. Record the top-two clean logit-margin central slope and the final-visit residual. These are finite-FP observations, and truncation of the gradient frame can leave nonzero instantaneous slope. The selected readout contrasts and frozen frame come from calibration, never from test labels.
6. **Decision threshold:** describe gains on reporting-half tasks as exploratory. A positive conclusion requires repeat on independent math and algorithmic families, multiple source checkpoint seeds, matched compute budgets, and a registered sealed readout. Improvement against reversed visits and zero SAE codes is essential for an SAE/visit-specific claim.
7. **Boundaries:** the SCM-17 program supplies no formal topology certificate, pretrained VPD factor recovery, or Miller-type 4D surface invariant. Runtime must never automatically rent GPU or overwrite RMP weights.

The mock fixture tests only the adapter interface. Its synthetic source is deliberately randomly initialized and must never be described as trained RMP evidence.
