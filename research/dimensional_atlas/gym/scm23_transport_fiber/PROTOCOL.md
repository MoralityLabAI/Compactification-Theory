# SCM-23: frozen CPU head-fiber transport, preregistration

**Registered before new held-out intervention data.** Upstream frozen SCM-22 model and geometry source on `Compactification-Theory/main` (merged PR #206), three synthetic F11 models, exact integer arithmetic as gold. This experiment is independent of the original private SCM-20 checkpoint assay and is a controlled follow-up to SCM-22's post-hoc head-fiber result.

## Question
Inside the **same readout-head linear kernel**, does a calibration-derived rank-four donor-difference orientation, or a rank-four orientation selected using derivative transport through later recurrence, increase counterfactual mathematical transfer relative to a label-blind SAE-derived rank-four orientation? At matched per-pair Euclidean patch norm, what is the remaining gap to a head-readable rank-four frame?

## Frozen model and inputs
- Reuse SCM-22 `model.py` and `geometry.py` exactly. Three weight-tied synthetic 4-visit models trained from scratch with seeds 191, 1191, 2191, 400 AdamW updates, batch 128, no GPU; same independent F11 oracle and task-generation contract. Fresh training is deterministic; original SCM-20 private checkpoints are absent.
- At each seed, fit a shared TopK SAE on 2,048 unpaired states with the existing 250-step SCM-22 procedure. Form the unsupervised SAE-fiber and matched random head-fiber frames using SCM-22, with the same 192-pair calibration set (generator seed `model_seed+90001`).
- The linear-head kernel has 37 dimensions inside 48-dimensional CLS space. Because a final LayerNorm follows recurrent processing, a kernel direction is *not* guaranteed to be an exact nonlinear-output null. Report the linear residual and a final-visit control.
- On calibration pairs at fixed second visit (zero-based 1), fit a new rank-four **fiber difference-PCA** frame from donor minus recipient CLS, projected into the linear-head kernel. Fit a rank-four **fiber transport-gradient** frame from projections into that same kernel of gradients of `[logit(donor target) - logit(recipient target)]` with respect to a zero patch inserted into recipient CLS after visit 1, on *calibration only*. Target labels for this calibration come from the public F11 arithmetic oracle. For PCA use centered double-precision SVD. Refuse rank deficiency.
- A **visible difference-PCA** rank-four frame from the same calibration pairs is an upper comparison outside the fiber; the existing unrestricted difference-PCA is another upper comparison. Neither is a fiber-specific intervention.
- Freeze all frames and model/checkpoint hashes before generating heldout pairs. The test set is 256 pairs per seed, generator seed `20261201 + model_seed`, disjoint from the SCM-22 heldout generator seed. On each pair the first operation changes, other fields stay fixed, and exact outcomes differ. Keep recipient/donor pairs only if both clean predictions match their exact oracle outcomes; fail if fewer than 64 eligible per seed. All arms use identical eligible IDs.

## Intervention measurements
Primary visit is 1; patch is projected donor-minus-recipient CLS difference, renormalized to have **exactly the same per-pair L2 norm** as the unprojected donor-minus-recipient difference (strict error <= 1e-5). Compare: sham, full difference, unrestricted difference-PCA4, visible difference-PCA4, fiber difference-PCA4, fiber transport-gradient4, SAE fiber4 and random fiber4. The transport-gradient basis is frozen from calibration; at test time it is driven solely by donor/recipient hidden differences without target gradients or target labels.

A registered half-norm repetition is secondary. Also run final-visit controls for all rank-four fiber frames (the final LN caveat). Track per-case Boolean success, exact labels, mean unscaled squared projection fraction, zero-projection fallbacks, norm errors, projection rank, source hashes, calibration and test signatures, and paired discordance.

Primary criterion: in all three seeds, fiber transport-gradient4 must exceed the SAE-fiber4 and random-fiber4 by >=5 percentage points in counterfactual transfer and reach at least 10% absolute fidelity. Record negative verdict if it fails. The main scientific estimand is each method's heldout donor transfer percentage at matched norm, not a change in baseline clean model accuracy (weights never change during this assay).

## Inference and leakage rules
Calibration gradients may use supervised targets from calibration cases. Final heldout gradients, correct programs, hidden futures, or model outcomes cannot affect the patch or frame. Gold is read only for eligibility and post-prediction scoring after all arms are frozen. Freeze frames and log hashes before test generation. The finite F11 program families recur across splits, so test pairs are generator-signature disjoint rather than a withheld algebraic family. Pooled 768 pairs are nested inside three model seeds; paired p-values are descriptive only.

## SCM-20 checkpoint-level read-only gate
Provide an independently runnable adapter for the SCM-20 host: load the already frozen model/frames and common-eligible pair records, compute rank-four fiber-restricted difference-PCA on the original 64 calibration pairs and norm-match against the existing native-write span **on each pair**, then score the same IDs. Freeze any newly fitted frame before reading final records and forbid any optimizer or checkpoint writes. Trained comparisons remain unexecuted here because original SCM-20 model weights, gold and pair cache are private. Do not edit historical SCM-20 results.
