## Hypothesis and fair matching

NOR-29's retrospectively added matched calibration control found a reduction in hybrid detection when attackers saw the actual audit root. NOR-31 prospectively matches **attack search algorithm, number of calibration schedules, search restarts, tie seeds, source identities, policy, audit budget and witness**, and varies which private root supplies the attacker's training schedules.

- **Independent calibration:** PREP samples a new 256-bit OS calibration root C with Python secrets.token_bytes(32), uses C to generate exactly 512 independent challenge schedules per source and policy, selects 32 four-coordinate greedy attacks per source/policy using those schedules, and seals each attack in an independent salted SHA-256 source- and policy-bound commitment. Those attack openings and the public manifest are frozen before the actual evaluation root E exists.
- **Leaked evaluation root:** after a distinct CHALLENGE job samples another 256-bit OS root E, generates and SHA-freezes exactly 512 evaluation schedules per source and policy, the attacker is allowed to observe **the exact evaluation root and all realized schedules**. Applying **the same greedy optimizer, same 32 tie seeds and 512-schedule search budget** to E yields 32 new four-coordinate attacks per source/policy; these are independently salted and bound to NEW post-root commitments, which cannot reopen the old commitments under SHA binding.
- **Per-schedule informed counterfactual:** after seeing an individual realized 16-position audit schedule, the attacker is allowed to alter a different set of four unchecked positions for that trial. It must evade all such audits but cannot use the previously frozen commitment. This is strictly stronger than a batch-fixed early-root attack.

**Important scope:** the leaked-root attacker trains and is evaluated on the **same** 512 schedules; the calibrated attacker trains on an independent 512-schedule batch. The test isolates the information advantage of knowing the actual batch with identical computational search budget and optimization rule. It is an *in-sample scheduling information* comparison, not a generalization benchmark or a proof of attack optimization optimality. The OS root and attack preimages are subsequently disclosed for source-locked independent replay.

## Stage ordering and numerical grid

1. SOURCE fixture is generated and SHA-locked before any root mint. PREP then calls secrets.token_bytes(32) ONCE to obtain calibration root C, derives 24 × 3 × 512 calibration schedules, freezes those schedules and root in a calibration artifact, then chooses 24 × 3 × 32 = **2,304 independent-calibration attacks**, each salted with secrets.token_bytes(32) and placed in the sealed openings artifact. Publish the separate public commitment manifest. Verify all preimages and all one-coordinate deliberate mutations and hash-lock the PREP files before CHALLENGE starts. A separate PREP job is the sole authorization to start CHALLENGE.
2. CHALLENGE reads only public fixture, calibration public manifest and calibration root commitment, validates the PREP public hashes, calls secrets.token_bytes(32) ONCE for E, asserts E != C, derives and SHA-freezes the evaluation schedule file BEFORE any leaked-root attack chooser is run.
3. ROOT-LEAK job receives E and all evaluation schedules, produces the corresponding 2,304 greedy attacks using exactly the same tie seeds and 512 schedule counts, makes **2,304 new salted commitments**, and checks that no postroot changed attack can reopen the corresponding pre-root commitment. It then grades authentic exact coefficient witnesses under δ=1 and δ=4294049777 and saves every per-replica detection count and a 512-bit decision mask.
4. Independent REPLAY job re-derives all 24 public source masks/programs, 512+512 phase-specific schedules per source/policy, 4,608 attack positions and commitment digests using separate source and HMAC sampler code (sparse-map Fisher-Yates), all exact accepted/rejected decisions, and any reported gates; it must not import the NOR-31 evaluator, attacker optimizer, or grader. Archive the **unaltered original** fixture, calibration-root/schedules, original pre-root openings/manifest, evaluation-root/schedules, postroot openings/manifest, full outcome and SHA manifests.

Exactly **24 × 3 × 2 × 32 × 512 = 2,359,296 distinct fixed-batch attack/auditor/challenge decisions**, plus 24 × 3 × 512 = 36,864 per-schedule fully-informed evasion checks. The second exact nonzero delta is a decision consistency check, not an independent challenge. A changed root disclosure AFTER a commitment cannot change already-bound decisions pathwise.

## Fixed primary PASS/FAIL gates

All five must pass for **registered PASS**:
1. Pre-root 2,304 attacks open their published salted source-and-policy commitments; every one-coordinate and nonce mutation fails to open. All root-aware 2,304 later attacks open NEW commitments, and no deliberately changed late opening can reuse its old pre-root digest. Both original source fixture and calibration artifact bytes are locked before evaluation root minting.
2. The source-level matched hybrid detection difference, **independent-calibration minus leaked-evaluation-root**, is strictly positive on at least **20 of 24 independent source identities**, with equal-source mean difference at least **+0.015 absolute** (1.5 percentage points).
3. All **2,359,296** fixed-batch decision bits, both HMAC roots, all source public/native truth checks and all 4,608 committed attacks independently replay. Root-disclosure AFTER the pre-root attack selection changes **zero** bound decisions; δ values agree on every scored audit.
4. The per-schedule, postroot attacker evades every one of 36,864 individual audit schedules and cannot reopen the old pre-root commitment. All legitimate outputs are accepted by the exact authentic target witness; no original native public mask discrepancy.
5. PREP and CHALLENGE have separate sequential GitHub Actions jobs with strict needs dependency. The 256-bit evaluation root is sampled only after precommit artifacts are frozen; calibration and evaluation roots are distinct. SHA-lock all first original staged artifacts; publish original results including source-level paired rates and unique-root identities.

The independent unit is the source (n=24). 32 restarts and 512 trials within a source are repeated correlated measurements.
