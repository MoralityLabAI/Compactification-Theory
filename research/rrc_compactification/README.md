# RRC-01: symbolic compactification of restricted partitions

**Status (2026-11-09):** completed, deterministic **CPU-only** finite-coefficient experiment. Eight unit tests and the source-hashed receipt are locally verified. No GPU run, neural training, new infinite-theorem proof, or previously unknown identity is claimed.

This experiment asks whether a short list of coefficients generated by a **local** constraint can reveal a compact **global arithmetic** rule that accurately predicts unseen counts. The Rogers–Ramanujan identities supply an unusually clean positive control: the answer is known in advance, but the recovery routine sees only integer counts from an independent local recurrence.

## Exact mathematics

For `s=1` or `s=2`, write `F_s(q)` for partitions whose neighboring parts differ by at least two and whose smallest part is at least `s`. Their generating functions are

\[
F_s(q)=\sum_{k\geq0}\frac{q^{k^2+(s-1)k}}{(q;q)_k},\qquad
(q;q)_k=\prod_{j=1}^k(1-q^j).
\]

**Derivation of the sum, without invoking Rogers–Ramanujan.** A partition with exactly `k` parts `λ_1≥...≥λ_k≥s` and gaps at least two contains the staircase `(s+2(k-1), ..., s+2, s)` of sum `k²+(s−1)k`. Subtract it componentwise. The remaining nonnegative weakly decreasing list is a partition with at most `k` parts, with generating function `1/(q;q)_k`. This gives the sum exactly.

**The nontrivial identity** adds an arithmetic product:

\[
F_1(q)=\prod_{j\geq1,\;j\bmod5\in\{1,4\}}(1-q^j)^{-1},
\qquad
F_2(q)=\prod_{j\geq1,\;j\bmod5\in\{2,3\}}(1-q^j)^{-1}.
\]

The infinite identities are established mathematics. The finite tests here do **not** prove them. For a formal proof, see the [Archive of Formal Proofs Rogers–Ramanujan entry](https://isa-afp.org/entries/Rogers_Ramanujan.html); for the analytic and combinatorial forms, see [MathWorld](https://mathworld.wolfram.com/Rogers-RamanujanIdentities.html).

## Separate mechanisms

1. **Local counting teacher:** With maximum allowed part `L`, `G_L(q)=G_{L-1}(q)+q^L G_{L-2}(q)`, initialized to `1` below the minimum part. This computes exact partition coefficients without modulus assumptions.
2. **Staircase / q-series teacher:** Independently compute the finite degree truncation of `Σ_k q^{k²+(s−1)k}/(q;q)_k`, maintaining the `k`-factor inverse Pochhammer product.
3. **Symbolic rule learner:** From **only degrees 0–64** of the local teacher, compute unique formal Euler-product exponents `a_m` defined by `F(q)=∏_{m≥1}(1−q^m)^{−a_m}`. Fit the smallest modulus `m≤12` whose residues have stable binary exponents, with at least two occurrences per residue.
4. **Prediction:** Use the recovered `(m, residue mask)` to count partitions into unrestricted multiples of allowed part values up to degree **256**. Compare predictions on coefficients **65–256**, which were withheld from fitting.
5. **Controls:** Replace the local gap by 3 and try the same rule learner. Separately rotate the learned residue mask, keeping modulus and code length unchanged.

Extraction uses exact integers and the logarithmic derivative

\[
n f_n=\sum_{k=1}^n b_k f_{n-k},\qquad
b_n=\sum_{d\mid n}d a_d.
\]

This recurrence uniquely determines `b_n`, then the Euler-product exponents `a_n` by divisor subtraction. Symbolic recovery therefore has an auditable, deterministic target, with no language-model judgement step.

## Registered result

| Partition family | Inferred modulus | Allowed residues | Held-out degrees | Held-out mismatches |
|---|---:|---|---|---:|
| Gap ≥2, smallest ≥1 | 5 | {1,4} | 65–256 (192) | 0 |
| Gap ≥2, smallest ≥2 | 5 | {2,3} | 65–256 (192) | 0 |

The `gap ≥3` control finds **no** binary periodic Euler-exponent rule with modulus at most 12 on the 64-degree prefix. The rotated first-family rule `{0,2} mod 5` fails immediately at held-out degree **65**. These are two selected falsification controls, not a measured false-positive rate over all alternative partition families.

The recovered rule has a **10-bit illustrative description** using an Elias-gamma code for the modulus `5` (five bits) plus a five-bit residue mask. This compares with a 64-bit literal membership table for parts 1–64. The comparison excludes the rule interpreter, fitting algorithm, model weights, generating-function coefficients, and all runtime memory. The local recurrence also has a short algorithmic description. The result is a compact equivalent *grammar*, with exact finite held-out transfer, rather than evidence of a ten-bit complete solution to arbitrary partition counting.

## Reproduce

Python 3.10+ standard library, from the repository root:

```bash
python -m unittest discover -s research/rrc_compactification -p 'test_*.py' -v
python research/rrc_compactification/rrc.py --check --out research/rrc_compactification/results/rrc01_n256_t64.json
python research/rrc_compactification/rrc.py --train 64 --degree 256 --modulus-cap 12
```

The checked JSON receipt records the SHA-256 of the source file and complete oracle coefficient vectors. Regeneration detects source drift, and the CI workflow only runs these CPU commands. Maximum runtime is governed by exact integer polynomial DP (`O(N²)` in the evaluation degree); peak arrays are `O(N)` for fixed gap. No checkpoint downloads are required.

## What to test next

A symbolic learner that is told the **form** of Euler products will recover a periodic mask if one exists. This is a constrained identification task, not a discovery claim about arbitrary algebra. The next rigorous experiment is a *family-disjoint* holdout: generate many local rule grammars, with unknown or absent product forms; train a small recurrent model to output a candidate program **and a finite verification certificate**. Compare its exact held-out transfer and grammar bits against an enumerative grammar search. Include out-of-family abstention, adversarial prefix collisions, and decoder/runtime costs. Only then test whether loop depth helps search for the symbolic invariant.
