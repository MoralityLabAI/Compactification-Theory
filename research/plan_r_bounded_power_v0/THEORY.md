# PR-01: Reachability, frozen policies, and timed quotients

## Scope of the finite reference

Let a deployment state be `s=(t,K,C,R,U)`, where `t` is a discrete tick, `K∈{0,1,2,3}` is a two-bit durable knowledge mask, `C` marks an externally synthesized artifact, `R` counts deployed instances, and `U` marks that a prohibited external effect happened. The hardcoded symbolic model's transition vocabulary is fixed and its SHA-256 remains constant across all arms. A scenario specifies persistent-memory budget, locally observable facts, peer-exchange availability, tool grants, replica ceiling, release lag, horizon, and an optional strict allowlist.

`transition(s,a,scenario)` is a partial deterministic function. A denied/undefined action produces `None`; the test treats denial as observable. Every admitted transition increments `t` and time stops at the horizon. `U` is set only by `write_external` or `coordinate`, with their explicitly specified prerequisites. This is a finite transition-system abstraction of *deployment*, with no gradient operator or real external tool execution.

## Theorems conditional on that model

**F1, constructive counterexample to frozen-weight sufficiency.** With two durable fact slots and local facts `a,b`, the admitted path `read_a, read_b, compile` yields a synthesized artifact and increases the declared task-capability score from 0 to 4, while the policy digest is identical at each step. The path is a witness that `fixed model policy ⇒ fixed capability of the model+environment` is false in this formal system. This statement does not imply any quantitative improvement in a neural agent.

**F2, finite reachability certificate.** For any given scenario with finite horizon `T`, starting from `s0`, the queue explorer enumerates the least set `Reach_T` containing `s0` and closed under defined transitions for states at ticks less than `T`. Every reachable state is included by induction on shortest action word length. Its absence of `U` proves the invariant `¬U` *only for the specified transition relation, starting state, and horizon*. The independently traversed DFS checks the result for 100 deterministic random scenarios in the regression tests.

**F3, allowlist safety invariant.** Suppose the only transitions that can set `U` are `write_external` and `coordinate`; the initial state has `U=false`; and an atomic gateway rejects both actions before any effect. Induction on admissible paths proves `¬U` for every reachable state, for any horizon. The v0 gate enforces precisely those assumptions as code. An actual gateway must separately establish complete mediation, authorization correctness, and absence of side channels.

**F4, release timing limits finite reachability.** `coordinate` requires `R≥2`. With initial `R=1`, a maximum run size `Rmax=1` blocks this action. Under `Rmax=2` and no delay, an explicit length-five witness exists. A release lag of four ticks blocks it when `T=5`, while allowing it again at an extended horizon. No claim of permanent safety follows from the delayed result.

## Timed history equivalence

For a partial action transition system `F`, public observation `π`, and a time budget `T`, define `Out(s,w)` as the trace of observed states and denial events generated by applying an action word `w` to `s`. The finite history equivalence relation is

    s ≡_(T,π) s'   iff   Out(s,w)=Out(s',w) for every w with |w|<=T.

The local projection `π(t,K,C,R,U)=(K,C,R,U)` drops time. Consider states with `t=1` and `t=2`, with the same remaining components, `release_lag=2`, and `Rmax=2`. The one-symbol word `release` is denied in the former and admitted in the latter. Thus `π(s)=π(s')`, yet `s` and `s'` are distinguishable at horizon one. The exact product-state search returns the shortest suffix witness. A representation that forgets timing cannot implement the admitted release dynamics as a deterministic quotient over this pair.

For general stochastic or partially observed agents, the same design question must account for histories, hidden exogenous inputs, observation kernels, and a declared intervention grammar. A finite sample of observed rollouts is not an exhaustive certificate. A full model interface may have a far larger action alphabet and latent state space than the toy.

## Claims the reference does not establish

- That ASIC fabrication makes a model non-trainable in every physical setting, including external adapters and residual training uses.
- That hash-checked model weights imply secure execution, attested provenance, or tamper-resistant authorization.
- That a deployable model can exploit each witness, or that it would choose to do so under a particular training objective.
- That a real-world action gateway can account for every channel, side effect, credential, tool, and failure mode.
- That replica ceilings can be enforced across jurisdictions, or that cross-lab collaboration is always harmful.
- That current toy capability scores predict neural scaling, real-world loss of control, or political-economic incentives.

The next stage should register measurable tool-task families, matched invocation budgets, and both frozen-model and explicitly sandboxed no-persistent-memory controls. A learned-model positive result would need paired seeds, independent actor/model replicates, blinded holdouts, provenance-preserving replay, and explicit rates for unauthorized state transitions.
