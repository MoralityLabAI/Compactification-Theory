## Model and scope
This is an algebra-only **single normalized reciprocal series** benchmark. It measures one exact `R` inverse of a signed integer source `F` and its independent NOR45-format full-output Merkle root. It **does not** expand NOR45's independently authorized signed-native grammar to 3073 coefficients, and does not certify a new session/authority/provider protocol. The original NOR50/49 independent authenticated controls run unchanged in source-free CI. No scientific model evaluation or semantic truth claim. The public input alone determines its inverse mathematically; the precomputed supplied inverse is untrusted and must satisfy `F*R == 1 mod x^m` over signed integers with exact no-carry convolution. Every returned output is the entire exact vector.

## Completely new 48-source public-only factorial source panel
Use precisely `replicate=(0,1)`, `m=(769,1537,3073)`, `profile=(s4-b2,s4-b8,s4-b16,s1-b2)`, `family=(signed_random,alternating)`, for **48 new source identities**. A profile `sA-bB` means coefficient stride A, magnitude bit width B. Set `F[0]=1`. For `i>0`, set nonmultiples of stride to zero and for every multiple of stride draw magnitude uniformly in the integers `[2^(bits-1),2^bits-1]`. The signed_random family uses a separate seeded fair random sign per active position; alternating family chooses sign `(-1)^(i//stride)`, while drawing independent magnitudes. Use `random.Random(int.from_bytes(sha256("NOR51/SOURCE/v1|rep|m|profile|family"),"big"))` and fixed nested iteration order rep, m, profile, family. Serialize every public coefficient as canonical decimal text. Source ID is the SHA-256 of canonical JSON containing *only* its grid coordinates and the input vector; source IDs must be unique and the generator must prove all 48 parameter cells present. Public-only fixture carries neither inverse, root, timing, production trace, hidden target nor private world. Freeze the **source SHA and 48 source IDs in one upstream job**, then run a dependent, separate first CPU job. No source revisions after its first timing.

The input distribution has a controlled sparse stride 4 across bit widths 2,8,16 and an additional dense stride-1 bitwidth-2 comparator. **Between-profile bitwidth and density differences are not independent in that extra comparator**, so subgroup descriptions must identify both fields. All sources are synthetic and public.

## Resource caps
Retain NOR46/NOR47 `MAX_COEFFICIENT_BITS=32768` and `MAX_PACKED_BITS=120000000`, strict builtin signed int type, `F[0]=R[0]=1`, length equality, full no-carry Kronecker identity check. For supported coefficient patterns a conservative bound on reciprocal bit growth is `B*floor((m-1)/stride)+1`, where `B` is the input magnitude bitwidth, from `|inverse_j|<= (1+(2^B-1))^j` on reduced support. For `m=3073, stride=4, B=16` this is **12,289 bits**, safely below the 32,768 coefficient cap, while the corresponding full packed bound is below 120 million bits. Recalculate actual bounds before each verifier multiplication; if any original source exceeds caps, preserve the original FAIL rather than replacing the source. Exact values are Python signed integers and GMP mpz, with no modular field reduction.

## Three exact timed arms, five interleaved repeats per source
1. `native_single_R_root`: original NOR45 independent exact `unary(source,"R")` **once** plus independent `independently_computed_root()`. This equals NOR50's already-memoized single-R direct baseline; no redundant inverse calls.
2. `gmp_verify_reference_root`: precomputed **untrusted** inverse witness is validated by NOR47 `gmp.full_gmp(source,witness)`, requiring every signed coefficient of the product to equal `(1,0,...,0)`, then build the same independent full-output Merkle root. No witness producer cost in this verifier-only arm.
3. `newton_produce_verify_root`: construct the exact inverse via dyadic doubling `G' = G(2-FG) mod x^k` with two NOR47 `gmp.full_gmp` calls per doubling stage, verify the final full signed `F*G=1 mod x^m` again using NOR47 GMP, then build the same root. This is an end-to-end generator+verifier arithmetic arm.

Before arm timing, compute the independent NOR45 reference inverse **once per source**, record outside-arm exact native witness-generation time, serialize the witness to canonical decimal JSON, record byte count/serialization time, and compare it to a Newton inverse. All three arms return the same exact output and Merkle root on every valid source. Source-specific arm order is deterministic hash-seeded/interleaved for each of five repetitions; record every wall-time sample, source-level medians, CPU/OS/Python/GMP metadata and outside-arm witness/serialization costs. Pin `gmpy2==2.3.2`, `cryptography==46.0.4`, Python 3.12, ubuntu-24.04, single thread and no global verifier mutation. Source parsing and transport are excluded equally. Producer and verifier runtime together are charged in arm 3. Reject tampered witness, non-integer, non-unit, mismatched length, and overcap examples in predata toy-source tests.
