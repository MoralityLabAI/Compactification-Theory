# OIC-18 implementation lock | 2026-11-10

This lock freezes the implementation and evaluation design **before OIC-18 training outcomes were inspected**. It implements the existing [OIC18_PROTOCOL.md](OIC18_PROTOCOL.md); n>=12 OOD cases are prospective for this run.

- OIC-16 original Fourier filter is reused from its archived **20** fits (clean/fault-augmented, 5 seeds, full/heldout) as the matched 14-parameter baseline. Each new model uses the identical OIC-15/OIC-16 seeded training batch generator.
- New emissions: temperature-rescaled centered Fourier with `tau(n)=1+sigmoid(t)*((n/5)^2-1)` (15 params); von Mises-shaped `logit=a-softplus(k)*(n/5)^2*(1-cos(2pi z/n))` (13 params); equal-parameter higher-harmonic Fourier `c0+c1 cos(2pi z/n)+c2 cos(6pi z/n)` (14 params). The transition operator remains the OIC-16 learned five-shift family-conditioned circulant kernel. All n-dependent phase sharpening is a declared architectural prior, not a discovered general law.
- Exact model, init and optimizer are in `oic18_model.py` and `oic18_train.py`. Training budget is 500 Adam steps x 128 simulator episodes, learning rate 0.035, prior OIC-16 kernel discreteness penalty `.008`, five seeds 0..4, full and held-out phase splits, clean and independently 4%-flipped/4%-erased raw-sensor augmentation conditions. The original baseline OIC-16 was trained with the same budget.
- Training phase counts are n=4,5,6. Held-out phases are z0=1 and z0=n-2. Evaluation phase counts are n=4,5,6,7,8,12,16,24,32,64; all seeds, all phases and both family labels. Clean primary outcome is balanced family classification after n active probes. Secondary outcomes include Brier, passive-prior deviation, phase-equivalence class posterior, alternating and latch schedules, every single raw-state flip and marked erasure on the n+2 even-phase latch. At each even n, the exact min-distance oracle is the reference ceiling. A separate OIC-15 GRU is an unmatched-compute input-matched control.
- Acceptance: >=10 percentage point OOD improvement in n=24 clean identification relative to frozen OIC-16 (mean over the matching five-seed, phase-split condition), while retaining n=7,8 clean accuracy and prior-level passive posterior. Fault robustness is reported independently and required for a **joint** claim of robust transfer. Worst-case initial-phase accuracy is reported separately from aggregate.
- Explicit cyclic label shift, reflection, and non-dihedral conjugation of latent labels are controls; the public histories should remain unchanged under *consistent* relabeling. A deliberately mismatched hidden generator and readout is an invalid comparator and is excluded.
- Per-model resource ledger covers learned parameters, 4n belief cells, 5 kernel shifts x 2 families and per-step arithmetic; baseline exact group projection and decoder remain structurally privileged ceilings.

The tests verify the exact finite data-generator contract, numerical replay from archived learned weights and no passive leakage.
