# NOR-57: authenticated exact witness source-conditional native/GMP dispatch

The first prospective [registration](REGISTRATION.md) was frozen at commit **f0a6091f918217138d466456c34fcc12ac8f3907**, before any new NOR57 public source generation, witness signing or first CPU timing. It follows the immutable [NOR56 first 3/5 engineering FAIL](../nor56_batch_codec/RESULTS.md), where authenticated signed compact-v2 decoding was a small fraction of complete verifier cost. Earlier NOR54/55 precision-dependent speed results motivate testing a frozen **public-source-only** native/GMP selector.

All three [exact signed acceptance modes](accept.py) consume **identical** NOR56 signed compact-v2 wire bytes and the same independently pinned original full source, source SHA, output reference root, provider fixture public key, full length, support stride, session, sequence and verifier challenge nonce. Every arm runs one shared authenticated source/header/replay signature verifier, exact compact-v2 decoder and original full NOR47 coefficient/packed resource caps. Its only branch is the reduced exact signed identity:

- **Always fast GMP:** NOR53 packed GMP signed product must equal the exact reduced unit polynomial, with full output/root.
- **Always native recompute:** from the independently trusted reduced source, compute the original NOR45 exact inverse once and compare **all** supplied reduced and original full witness coefficients. The full original Merkle root and replay checks remain mandatory.
- **Frozen public selector:** choose native iff the **verified public source** has stride 4, actual max input coefficient bit length exactly 16, and full length 769 or 1537. Otherwise use GMP. The fixed rule chooses 8 of the 60 registered source cells for native and 52 for GMP, independent of supplied witness, signed payload, root, nonce, provider or measured runtime.

The new deterministic [public-only 60-source generator](cohort.py) uses domain NOR57/SOURCE/v1 and the same 2×3×5×2 grid as NOR56. It excludes the 348 original first NOR51–56 source IDs through SHA-verified immutable repository archives. A separate upstream CI job must upload first public-only SHA before a dependent first CPU job generates any inverse, signature, full root or runtime.

The [three-arm CPU runner](benchmark_cpu.py) executes five source-seeded interleaved repetitions per identity with **the same five prebuilt signed envelopes** in each arm, on one Ubuntu24.04 Python3.12 gmpy2 2.3.2 and cryptography46.0.4 runner. Each arm has an independent replay guard and reconstructs the same full original signed inverse vector and independent NOR45-format Merkle root. Source-level reference inverse, original full witness JSON bytes and signer-side envelope creation are measured separately outside timed verification. [Source-free tests](test_accept.py) cover exact same-wire acceptance, wrong source/root/provider/signature, stale and repeated nonce/session, forged stride/bitwidth and complete witness alteration. Previous NOR50 signed-native tests and NOR56 immutable negative original audit remain unchanged.

Frozen first engineering criteria: whole-panel **ratio of sums of 60 source medians** selector/always-GMP <0.95x; median sourcewise always-native/always-GMP <0.85x on exactly 8 prospectively native-selected cases; median selector/always-GMP <1.10x on the other 52; 60/60 signed complete vector/full original root and hostile tampering checks; upstream source SHA, 348 old identity exclusions, fixed source routing, five repeats and independent original byte-exact first archive SHA audit. Any first FAIL remains unchanged and requires separate follow-up labeling.

The output is a transparent synthetic integer formal-series witness, rather than a cryptographically succinct or zero-knowledge proof. m3073 is outside the original NOR45 signed-native-program grammar; a deterministic, publicly documented Ed25519 private test fixture key cannot authenticate a genuine remote provider or true-world data. Sender/transport costs are excluded equally from verifier-only timings.

**First original source/CPU trigger:** registration, same signed-wire exact acceptance, public-source selector and adversarial predata controls passed before any new source generation. This commit starts the first upstream public-only 60-identity SHA freeze, followed by a dependent first CPU job. All five original registered criteria, the eight native/fifty-two GMP source decisions and any first PASS/FAIL verdict remain unchanged.
