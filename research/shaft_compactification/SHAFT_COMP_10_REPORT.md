# SHAFT-COMP-10: Endogenous recurrent noise and model-aware semantic anchor design

**Evidence:** two independently trained 3,265-parameter CPU GRUs; a second held-out evaluation for the anchor-selection experiment; six new standard-library tests; Lean 4 conditional mathematics. All work uses local synthetic truth-table tasks. There is no network, replication, model survival after deletion, covert communication, or frontier-model inference.

## Question and experiment

COMP-09 assumes an independent binary symmetric channel with identical bit-flip probability for every query and anchor. A real recurrent network can forget certain tasks or query features before others. The errors may depend on its learned weights, objective label, recurrent depth and the specific sequence of state updates.

Let G = S4 × C2, with |G|=48, be the family of query-coordinate permutations and global output inversions. The source model supplies a four-bit behavioral signature on each anchor after twelve recurrent steps. Its true-task error is checked experimentally. The target model supplies its counterfactual four-query responses after 12, 24, 40 or 64 steps.

For an anchor a and candidate gauge g, define

  L_g(a) = sum over q of 1[source_a(q) != target_a(g(q)) XOR flip_g].

The inference algorithm receives only the paired signatures, never the task IDs. Its output is the minimum observed-Hamming-score gauge among 48 candidates. The metric **unique correct** requires the true gauge to be the sole minimizer, so tie-breaking cannot inflate the main success rate.

The original GRU architecture and training contract from SHAFT-COMP-06 are reused without changing model weights: 24 hidden units, synthetic 16-task four-bit truth-table goal embeddings, 600 Adam updates, length-12 training examples, and independent model seeds 101 and 202. Both are run in each source/target direction.

### Endogenous-noise experiment

For each pair and anchor design, draw 512 independent contexts of up to 24 paired anchors. Independently sample source and target recurrent prefixes. The source is measured at depth 12. Target depth varies from 12 to 64.

Baseline anchor cycles are one-hot (1,2,4) and balanced (3,5,6,9,10,12). A separate set of 192 calibration trials per design estimates the target's marginal bit error p at each depth, allowing a matched synthetic independent-BSC comparator. The comparator applies independent flips of exact target truth-table answers at the calibrated p. The real experiment perturbs **only the recurrent state trajectory** through ordinary task inputs, with no synthetic bit-flip or erasure injection.

The full raw numerical measurement is regenerated by [activation_noise.py](experiments/activation_noise.py), pinned to torch 2.10.0+cpu and NumPy 2.3.5.

The four query coordinates have sharply unequal error rates. With receiving model 202 on balanced tasks at depth 64, these rates are approximately 0.19%, 33.50%, 16.81% and 50.79%. With receiving model 101 on one-hot tasks, the second query is wrong approximately 71.86% of the time. These differences arise from the trained recurrent dynamics.

The independent-BSC control overpredicts gauge identification in several settings despite matching the *calibrated average* error. Other conditions show the reverse. Empirical success consequently depends on the relationship between errors and the candidate-gauge codewords, including across-query dependencies and persistent task-specific bias.

At depth 12, all source and target signatures in this study's sampled conditions match the synthetic tasks, as expected from the base-model training. By depth 64, the recurrent hidden states have lost information unevenly.

## A model-aware anchor-design problem

For each candidate goal a and incorrect gauge g, define the random score margin

  X_a(g) = L_g(a) - L_{g*}(a),     -4 <= X_a(g) <= 4,

where g* is the known synthetic reference gauge. From 192 *independent calibration prefixes per goal*, estimate

  mu_hat_a(g) = E_calibration[X_a(g)].

Choose the lexicographically first triple attaining

  **max_{A subset {0,...,15}, |A|=3} min_{g != g*} sum_{a in A} mu_hat_a(g).**

This optimizes the smallest estimated expected advantage over incorrect gauges. The algorithm exhaustively considers all 560 triples and repeats the selected three-task cycle for budgets 6, 12 and 24.

**Calibration boundary:** the synthetic reference alignment g* is given to this optimization procedure. Paired task references and target model measurements are available. The task is *calibrating a verification anchor panel* after reference correspondence has been established. This is a supervised reference-design procedure. It does not solve unknown semantics by itself, and the receiving model plus its weights remain available throughout.

Selection uses only calibration prefixes. Every number below comes from fresh evaluation prefixes. The second evaluation uses another independent random prefix stream with the *same* frozen trained models and calibration-derived triple.

For the hardest receiving-model-101, depth-64 condition, the calibrated triple identified the correct gauge uniquely in 471/512 samples in evaluation A (91.99%, Wilson 95% interval approximately 89.32%–94.04%). All numbers concern two fixed model instances and a finite task family.

The earlier clean-channel minimax design remains a mathematically valid result under its assumptions. Model-conditioned errors change which reference observations are informative. Even the lowest *average* bit-error design need not maximize the worst candidate-gauge score margin.

## Mathematics: concentration with correlated query errors

For a given wrong gauge g, assume each *anchor prefix* is sampled independently conditional on the frozen network, its goal ID and model configuration. The four query responses within a single anchor may be arbitrarily correlated. Put

  S_g = sum over a in A of X_a(g),    M_g = E[S_g] = sum mu_a(g).

Since every anchor contributes X_a(g) in [-4,4], Hoeffding's inequality over n independent **anchor blocks** gives, for positive M_g,

  Pr[S_g <= 0] <= exp(-M_g^2 / (32 n)).

A union bound across 47 incorrect gauges yields

  **Pr[wrong gauge wins or ties] <= min(1, sum_{g!=g*} exp(-max(M_g,0)^2/(32n))).**

This bound allows arbitrary dependence *within* the four observations of a single anchor block. Independence of randomly drawn anchor prefixes remains necessary. Its use on real models also requires a valid lower bound for each unknown population mean M_g.

The 192-prefix calibration uses a plug-in estimate. An optional uniform Hoeffding confidence allowance across 16 task types and 47 wrong gauges at confidence 1-delta is

  epsilon = sqrt(32 ln(752/delta)/N),

meaning each true per-goal expected score margin is at least its empirical estimate minus epsilon, simultaneously with probability at least 1-delta. At N=192 and delta=0.05, epsilon is approximately 1.266, often making a worst-case concentration certificate uninformative. The empirical gains are supported by held-out tests; the source does not claim a nonvacuous high-confidence population guarantee from the 192 calibration prefixes.

An exact deterministic certificate already formalized in COMP-09 is

  observed_minimum_code_distance > 2 * total_corrupted_bits.

The new [ClusterNoise.lean](lean/Shaft/ClusterNoise.lean) formalizes the consequence of an error budget bounded per anchor block, without invoking independence. It also proves a four-bit counterexample where **two observations each have one corrupted bit**, but the locations of those errors yield, respectively, a tie and a strict margin against an incorrect candidate. Thus identical scalar error rates do not imply identical gauge distinguishability.

## Controls, replication and limitations

- Separate frozen GRUs for the two directions; neither evaluation reuses the exact calibration recurrent prefixes.
- Source teacher accuracy is audited against the synthetic truth table.
- All 48 candidate gauges, including the true gauge, use identical observation access; tie frequency and unique-correct counts are distinct fields.
- The BSC comparator gets its error-rate estimate from separate calibration prefixes. This isolates the effects of task and coordinate-specific recurrent failures.
- A second evaluation stream checks the selected reference sets; model weights and calibration anchors stay unchanged.
- Full local outputs are available from the execution environment and SHA-256 hashes are pinned in [comp10_summary.json](results/comp10_summary.json). The repository contains the full scripts, which regenerate them.

The model's four-bit task objective was explicitly supplied during base-model training. Model-generated observation noise provides evidence about behavioral identifiability in a controlled recurrent system. Generalization to unseen objective families, independently evolved task semantics and latent objectives in frontier systems remains open.

From repository root with PyTorch 2.10.0+cpu and NumPy 2.3.5 installed:

```bash
python -m research.shaft_compactification.experiments.activation_noise \
  --trials 512 --cal-trials 192 --seed 86244 --out /tmp/comp10_endogenous.json
python -m research.shaft_compactification.experiments.adaptive_anchor \
  --trials 512 --cal 192 --evaluation-seed 83000 --out /tmp/comp10_adaptive.json
python -m research.shaft_compactification.experiments.adaptive_anchor \
  --trials 512 --cal 192 --evaluation-seed 93000 --out /tmp/comp10_adaptive_replica.json
python -m unittest discover -s research/shaft_compactification/tests -v
```

Lean proofs use the existing standalone v4.28 toolchain with `cd research/shaft_compactification/lean && lake build`.

Light GitHub CI runs standard-library finite tests, checks both optional PyTorch scripts' syntax, validates the pinned summary's expected fields and builds Lean. It does not retrain the GRUs during routine checks.
