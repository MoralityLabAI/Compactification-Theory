# COG-10: a locality obstruction to proof-step compression

COG-07's five-example certificate shares the exact goal-ancestry feature with its decoder. This follow-up separates the cost of computing that feature from the cost of learning the Boolean decoder.

## Locality theorem

Consider a deterministic token message-passing architecture on a directed rule-dependency graph. An edge from rule i to rule j means that i's conclusion occurs in j's premises. Each node's initial features depend only on its own rule, local counts, current known facts, a local goal indicator and shared scalars. At each pass its next state is a function of its previous state and the multiset of previous states of its outgoing neighbors (including itself). There is no global pooling, node-ID lookup, direct access to the goal's identity, or prior carried state in this first-decision statement. The functions can differ between passes. The COG-03 masked transformer at the first verifier decision satisfies this locality condition in exact arithmetic.

For every integer d >= 0 construct two disjoint chains of L=d+2 implication rules starting from a common known fact. In world A the goal is the terminal atom of the first chain; in world B it is the terminal atom of the second chain. The rule menu, rule ordering, initial fact and counts are identical across the worlds. Only the two terminal goal indicators change. The first rule of the first chain is a ready, fresh goal ancestor in A and a ready, fresh irrelevant rule in B.

The directed distance from that rule to its terminal goal indicator is L-1=d+1. Its labeled radius-d outgoing neighborhoods agree across the worlds. By induction on the passes, equal initial radius-k neighborhoods imply equal states after k passes: the center state and all states in the next input multiset agree by the induction hypothesis. Thus the first rule has identical state and identical local-head output in both worlds after d passes, even though its correct binary usefulness labels differ. Any deterministic classifier of that state alone makes at least one error on the pair. At pass d+1 the exact color-refinement signatures distinguish the pair; this means that information can arrive by then, without guaranteeing that trained weights use it.

With a uniform draw over the two worlds, the candidate classification error floor is 1/2 for that fixed rule at depth d. The bound is independent of width or numerical precision under the stated local architecture. It applies to the first decision. Previous-decision carry, global attention, global aggregation, external search, or a decoder with full graph access can change the conclusion. This does not prove a lower bound on arbitrary neural reasoning or transformer parameters.

## Finite collision theorem

Given a finite labeled sample and any deterministic feature signature phi, let n0(z), n1(z) count the two labels in signature class z. Every deterministic decoder that depends only on phi makes at least sum_z min(n0(z), n1(z)) errors on that sample. Choosing the majority label in each class attains the lower bound. If a refined signature determines the earlier signature, its minimum empirical error cannot increase (the earlier decoder remains representable). This is a statement about finite empirical representability, not generalization or a VC-dimensional theorem.

The script uses exact integer interning of the ten rational local features corresponding to COG-03 and the multiset recurrence. It computes the finite collision floor at each depth 0..16 on all four original COG-02 partitions. Color identifiers are shared across partitions solely to encode exact feature equality, with labels excluded from interning. The empirical oracle floor uses labels from each respective split. A separately reported decoder uses only training majority labels, defaults to negative for unseen signatures, and reports coverage. It is a baseline, not a compressed neural model.

A separate Boolean propagation begins with the local goal cue and propagates it backward via rule-consumer edges. The number of remaining false negatives after each pass measures the exact missed ancestry among ready, fresh candidates. Its false-positive count must be zero. Full graph closure agrees with the original source ranking labels. Unlike COG-07, the cost of recovering ancestry is visible as depth.

The locality theorem has a direct mathematical proof above; Python and a separate JavaScript enumeration check 65 concrete depth pairs. The exact corpus statistics are descriptive and do not require a statistical power calculation.
