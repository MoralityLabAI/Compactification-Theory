# RB-CG-09: context-shared proof obligations and certificate economy

## Motivation
CG-08's first verified native run failed the learned superiority gate (237/236 vs goal-slice 260). On deeper cases at 32 firings the learned actors certified no source-supported cases, while goal-slice certified all 48. Its four contexts reprove some globally available facts. This experiment separates deterministic proof reuse from learned allocation.

## Fresh source families
Reuse the unchanged CG-08 corpus generator, original RHMainLogic adapter, exact certificate contract, and MathCan pin 6d02b611c7358216379cb36952512a104e0bdb8e. New independent seeds 109901/109902/109903/109904, 64 train, 16 calibration, 24 depth, 24 bridge source families, with the original registered path lengths and gap mechanisms. Four matched cases per family, 512 cases total. Require fresh source signatures (no overlap with CG-08), unique case IDs and native reference replay. Same abstract interface across splits; neither this nor CG-08 constitutes an audit of classical RH.

## Context reuse
A context is the public base Γ plus a set A of local assumptions. If A is a subset of B, any Horn derivation in Γ,A can be transported to Γ,B. Each paid novel rule firing in A also makes that rule's conclusion available in every stronger context B, when not already known. Maintain a locally replayable proof trace in each context; each transported rule must have all premises available in the destination. No countermodel is transported upward from a weaker context. A stronger-context countermodel refutes the same target in a weaker context if it satisfies the weaker context's assumptions. These are native logical statements in Weakening.lean. Transport is logically free in the firing metric, but destination bookkeeping, proof trace length, rule scans and ranking computation are charged/reported separately; this is not a wall-time equivalence claim.

Three actor modes: isolated (no transport), shared (all legal choices, transport), dominant (shared, omit a candidate if the same rule can be fired in a strictly weaker eligible context). The latter pruning is safe for completeness with unlimited budget because the weaker action includes the stronger effect. This does not prove arbitrary optimality under stopping/scheduling costs. Use the same CG-08 stopping and certificate verifier in every arm. Independent support with a gap still needs a concrete model for one prescribed source obligation. A globally proved H trivially supplies E → H, so absence of a named final bridge alone cannot certify a semantic gap. Source relevance and logical validity are separate contracts.

## Policies and training
Compare global-first, backward goal-slice, and shared-relevance (sum inverse syntactic distance to outstanding goals over novel destination contexts). Evaluate each in isolated/shared/dominant modes under 8/16/32/64/128/256 firings. Two 737-parameter rankers (21 features, 32 hidden, seeds 141/149) learn on dominant mode, using only train-family action sets. Teacher obtains per-context canonical full closure plans as in CG-08, scores an available firing by the number of planned firings it would satisfy through transport, and labels all tied positive maxima. Fifteen percent exploration, 12 fixed epochs, AdamW .003, batch64; no test-based selection. Actor features include 16 original public features and five explicit reuse features. Full closure is reserved for teacher/reference, not test-time learned scoring. Rule scan counts and rank evaluations separate from actual paid firings. No hidden truth labels in observation.

## Gates
Primary architectural gate: paired goal-slice shared versus isolated, at 256 firings, must certify all held-out cases and reduce total paid firings by at least 10% on each held-out split. Also report per-class and per-case paired cost differences and partial-budget coverage; an apparent cost gain due to reduced coverage does not qualify. Secondary learned gate: both dominant learned seeds beat the strongest of the nine fixed controls by at least six combined certified cases across depth/bridge at 16/32 firings, with zero invalid certificates. The strongest symbolic baseline may make learning unnecessary. Independent native replay of every distinct accepted actor certificate and all reference cases, and axiom checks of Weakening.lean. Record failures and scoped interpretation. The certificate remains a typed mathematical critique with deterministic rendering, not free-form prose.
