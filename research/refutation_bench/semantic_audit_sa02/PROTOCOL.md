## Registered source
80 independent families; four factorial arms per family: clean/extra-axiom proof root crossed with matching/false advertised statement. Each arm shares its family's entire source. Random opaque names; a proof DAG contains branches, transitive aliases and dead axiom declarations. Statement definitions have separate alias chains. Exact closed propositions use bitset inclusion or nonempty intersection over a 16-element universe. Mechanisms are conclusion narrowing, premise expansion, existential witness strengthening and vacuity advertised as existence. No real RH theorem is in the source.

Family splits fixed before execution: train 32 (seed 9201), calibration 12 (9202), deeper test 20 (9203), unseen-mechanism test 16 (9204). Familiar mechanisms alternate narrowing/expansion. Unseen mechanisms alternate existential/vacuity. Proof and definition depths increase in the deeper split. All arms of a source family remain in its split. This is public reproducible data, not a confidential blind test. Do not train on the test oracle or source labels.

## Auditing game
Initially expose only opaque identifiers for the selected proof and advertised proposition. A paid read of a discovered declaration returns its kind, literal payload and immediate referenced identifiers. The actor cannot inspect unacquired declarations or global source metadata. Use a shared one-read-per-node budget; proof and semantic frontiers compete for it. Gold labels are not an observation. A forbidden axiom along an observed proof-dependency path is a positive policy-violation certificate; clean closure requires inspecting the entire reachable proof DAG. Type definitions in this generated fragment are axiom-free. Semantic match is exact normalized-expression equality; a false target has an independently evaluated finite counterexample (inclusion) or empty-intersection certificate. An extra axiom flags dependence under a policy even when the target is true. A defect verdict is justified by either certificate; a supported verdict needs both clean closure and a match. Partial evidence can be retained with abstention. Report each axis separately as well as verdict.

This is deliberately a restricted decidable semantic fragment. The two true propositions in supported pairs are definitionally equal. A missing bridge in general Lean is an open obligation, and truth of an unrelated target alone is not evidence for a submitted proof. The next corpus must include nondefinitional valid bridges and true-but-unsupported correspondence claims with explicit relevance rules. The source graph is generated metadata, not a general Lean dependency extractor. Its axiom closure claims are checked against native Lean output.

## Native and independent verification
Compile all family sources and selected root axiom audits using Lean 4.19.0. For all good targets compile a certificate using the selected clean root. For each bad target independently compile its negation; for a false inclusion also compile the failing bit witness. Check the selected bad root uses exactly its named forbidden axiom, even with other axioms in the file. Require zero admissions, no unexpected axiom dependencies, and 80 unique source hashes. Fail closed. Keep generated source, exact expected axiom records and full logs as artifacts. A standard-library baseline runner checks certificates from observed subgraphs against independently computed full-source gold, with tests for inaccessible reads, budget caps, paired split identity and exact full-budget verdicts.

## Frozen controls and metrics
At budgets 4, 8, 16, 32, 64, 128, compare random, lexical, proof-first, semantic-first and alternating obligation-first acquisition. Each receives identical visible inputs. Random seed is fixed per case and budget. Count correct supported/defect verdicts, false rejection, incorrect support, abstentions, verified per-axis evidence, mean reads, and four-arm joint correctness. Compare per split; no selecting a best held-out policy and rebranding it as preregistered. Report a full-graph oracle as a correctness ceiling, not a budget-matched policy. No neural result is claimed. The fixed baseline receipt will establish which budgets leave actual headroom before training a recurrent controller. Any learned campaign must freeze checkpoints on train/cal only, and compare to all these controls. Preregister the learned policy separately after observing SA-02 baseline results.

## Math
For generated proof DAG G, each forbidden axiom use is witnessed by a path from root to a forbidden leaf. A clean certificate is a rooted closed subgraph whose reachable leaves are admitted theorem bodies or allowed axioms. In this fragment, the graph is complete by construction. For mask inclusion, T(g,s) iff g & s = g; its negation iff g & ~s is nonzero. A least set bit provides a canonical finite counterexample. For existential intersection, W(g,s) iff g & s is nonzero; its negation is emptiness of that intersection. These certificates are decidable, and a correct policy can still abstain because evidence acquisition is budgeted. With only local reads, a path is a sufficient negative axiom certificate, while a clean assertion has a worst-case lower bound of reading every reachable proof node: an unread terminal or outgoing edge can conceal a forbidden axiom in an otherwise consistent completion. This lower bound assumes unrestricted unknown local graph completions; it is not a lower bound for Lean's kernel or arbitrary encoded source compression.
