## Sound interval search

For a partial box B, enclose each arithmetic expression's possible values with integer intervals. Use exact interval addition, conservative subtraction (clip to zero for Nat), endpoint-product multiplication, and division only by a positive constant singleton (the registered grammar uses denominator 2). For comparisons return forced true, forced false, or unknown; negation reverses these statuses. Discard a box only if some premise is forced false or the goal forced true. If all premises are forced true and the goal forced false, emit the lowest-coordinate corner as a witness. Otherwise split a widest coordinate, breaking ties by source order; process both children with the same rules. At singleton all statuses are exact. The tree partitions the original bounded domain. Exhausted frontier with no witness warrants a finite proof proposal; a budget cutoff warrants abstention.

Charge one interval evaluation per generated box, including root and discarded children. A split requires two remaining node credits. Each policy shares interval formulas, tree, splits, verifier and node charge; ranking is the only learned component. No evaluator may inspect unseen descendants or candidate truth at test time. Record candidate rank scoring and interval evaluations separately; CPU cost is not matched. Native reference certificates and each distinct accepted actor certificate must pass the unchanged CG-06 independent Lean replay.
