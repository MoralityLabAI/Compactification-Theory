# RB-CG-10: provenance, allowed derivability and semantic truth

## Scope
CG-09's 737-parameter context scheduler passed its secondary learned gate (326 each versus 304 best registered symbolic control); the primary transport savings gate failed. CG-10 addresses the historical critique distinction: a correct proposition, derivability from the permitted premise set, and dependence of the particular submitted proof are separate. This is a generated finite Horn fragment with native Lean proofs, not an audit of the classical RH theorem or a claim of arbitrary Lean proof extraction.

## Exact audit semantics
An environment consists of positive ground proposition facts and curried Horn rules, each declared with an opaque identifier and policy tag (allowed or forbidden). The selected theorem is a kernel-valid proof of an advertised atom using a declared chain of applications. The input specifies the allowed policy explicitly. It includes the raw source, selected theorem, conclusion, declarations and the explicit proof dependency DAG in a restricted parser representation. The declaration graph contains actual direct uses, not every premise in scope. A forbidden dependency can be a local environmental axiom, not an inconsistency.

Three binary questions are independently certified:
1. unrestricted semantic entailment of the advertised atom from all declared environmental propositions (positive proof trace or finite countermodel);
2. allowed derivability from only allowed declarations (positive trace or countermodel satisfying every allowed premise);
3. selected-proof provenance: forbidden dependency path, or exact complete reachable dependency closure containing only allowed leaves.

All submitted proofs in this experiment establish the advertised atom. Therefore unrestricted truth relative to the environment is positive. Do not conflate that with theoremhood without premises. For the allowed axis, failure requires an actual countermodel. For the provenance axis, a tainted proof of an allowed-derivable conclusion admits a repair by choosing a clean derivation. An unused forbidden axiom is a matched decoy and is not evidence of dependence. No unsupported axiom of False or classical RH proposition is asserted.

## Matched generation
128 independent source families, train 64, calibration 16, depth 24, clutter 24; seeds 110001/110002/110003/110004. 4 arms per family, 512 total. Each source includes two disjoint chains from independently named facts to the same goal, one allowed, one containing one forbidden axiom. Include unrelated forbidden facts and allowed/forbidden decoy chains. Randomize names and declarations subject to topological source order. Select either clean or tainted proof when both routes are available; for the necessary-forbidden arm remove the allowed route's start fact (replace that leaf by a forbidden assumption). Matched fourth arm is clean but has an unused nearby forbidden axiom (use the same clean proof graph with policy/declaration clutter changed). Three semantic/provenance labels: clean, tainted-but-repairable, tainted-and-not-allowed-derivable. Train/cal path length 2–4, depth 7–10, clutter 2–4 and 12–20 decoy nodes vs 3–6. A case's generated raw source is a namespace with opaque proposition constants (axioms representing uninterpreted propositions), environmental proof axioms, named proof aliases and selected theorem. The three axes are relative to the explicit allowed basis; native #print axioms closure will include proposition constants that form the shared vocabulary. Check the exact expected environmental proof axiom closure, separately from the vocabulary constants, and allowed kernel primitives. The positive proof certificates apply premises as universally quantified Prop arguments, not by silently importing forbidden axioms. Countermodels substitute True/False and prove the negation of the universally quantified allowed sequent. Each source family stays in one split. Public prospective cases, not a blind evaluation.

## Search and certificates
Two metered work queues: trace actual proof dependencies (read a discovered graph node, one unit) and derive allowed facts (one unit per novel Horn firing). Environmental allowed facts are initially known. The global proof is already kernel-verified by native source replay; unrestricted semantic entailment is certified by its selected declaration. The actor can stop only when the selected proof's provenance is certified and the allowed axis is certified. Proof transport is not a mechanism here: two proof axes use different declaration sets. A discovered forbidden leaf supplies a path from selected root; a clean proof needs all reachable nodes read. Allowed derivability uses an explicit trace or saturated allowed closure as a Boolean model. The scorer independently checks path/closure and allowed trace/model. No hidden label or precomputed full closure enters the actor. A partial audit may report separately verified axes but must abstain on a full classification. Charge graph reads and rule firings together; record scans and rank evaluations separately. Compare provenance-first, allowed-first, alternating, goal-slice, and learned action-set scheduling with identical transitions. Full information closure is a diagnostic ceiling. Native independent replay of every reference and distinct actor certificate, including exact #print axioms of the selected source theorem, positive allowed implication or negative allowed implication. Native audit corroborates the generated restricted dependency graph, not arbitrary source extraction.
