## The countermodel hitting-set formulation

Let Γ be the original satisfiable finite clause set, Γ' the retained subset, Δ = Γ minus Γ', and T the goal. The nonentailment witnesses are W = {v : v satisfies Γ' and falsifies T}. For each omitted clause h define E(h) = {v in W : v falsifies h}. A set R contained in Δ repairs the advertised implication precisely when the union of E(h) for h in R equals W.

Proof: A valuation contradicts the repaired implication iff it belongs to W and satisfies every member of R. Such a valuation lies outside all E(h). Its absence is equivalent to the union covering W. Because Γ is satisfiable, every subset Γ' union R remains satisfiable. This rules out repairs that succeed merely by introducing inconsistency in this particular corpus.

The minimum-cardinality repair problem is finite set cover. Dually, each v gives a nonempty subset D(v) of omitted hypotheses it violates; a repair must hit every D(v). The full source entailment guarantees nonemptiness. A single countermodel can rule out every candidate repair that it satisfies. It cannot establish that a surviving candidate suffices. A validated UNSAT proof of Γ' union R union {not T} certifies sufficiency. For a sufficient repair R, a valuation satisfying every member of R except h, falsifying h, satisfying Γ' and negating T is an irredundancy witness for h. Irredundancy is distinct from minimum cardinality.

## Counterexample-guided repair

Maintain a finite observed countermodel set V. Compute a smallest hitting set of their violated-omission sets, with a deterministic tie rule. Test the resulting hypothesis set using the verifier. If SAT, add the newly returned total valuation and repeat. If UNSAT, the repair is globally minimum-cardinality: every globally valid repair hits the observed constraints, so their minimum is a lower bound, and the accepted candidate attains it. Each new countermodel excludes the current candidate. Termination is guaranteed with unrestricted finite SAT calls, provided Γ entails T and all checks are exact. A resource-limited controller can return a verified upper bound and observed hitting-set lower bound separately, or abstain.

This is a theory for finite clauses, and extends to arbitrary semantic entailment only when suitable sound witness and entailment checkers are available. It does not make a search timeout evidence of unprovability. The present CG-03 experiment restricts repair to a single omitted hypothesis and uses a planted chain. A subsequent CG-04 should allow several independent gaps, several equivalent repairs, and decoys that cover some countermodels without restoring entailment. Compare exact bounded hitting-set search, random, greedy coverage, and learned candidate ranking.
