## Model, targets, compute
A candidate-scoring actor consumes only current acquired graph and frontier features (role, visible depth, frontier widths, known node counts, read count; no identifier embeddings or unseen metadata). Every read updates a 24-dimensional GRU state from selected candidate features and observed kind. The static control uses the same candidate features and a comparable hidden width with no recurrent history. Two initialization seeds 71/73, AdamW lr 0.003, 12 fixed epochs, batches 16 trajectories, no test-dependent checkpoint selection. Record parameter counts, exact checkpoint hashes and training loss. CPU only. At train states the omniscient oracle supplies the complete optimal next-action set: choose a read a when 1 + residual_min(S union {a}) = residual_min(S). Compute residual costs of shortest weighted forbidden-axiom path, target expression closure, and union of all required proof/type nodes. A weight of zero applies to an already acquired node, one otherwise. Use two trajectories per train arm, one purely optimal and one with 15% random valid exploration; all trajectories stop at the first certified verdict. Train on negative log probability assigned to the optimal action set. No test labels or oracle schedules enter actor observations or training. Evaluate the fixed final weights on calibration and test separately.

## Baselines
At read budgets 8,16,32,64, evaluate original five acquisition orders and stronger target-first, proof-depth-first, proof-breadth-first, target-then-depth-first, adaptive frontier-size policy. All stop at the first independently accepted verdict or exhaustion. Target-only first resolves the advertised expression without resolving the submitted type, then obtains proof closure and match if needed. Proof DFS/BFS resolve proof obligations before target and source, using only observed edge order. The adaptive control chooses the open proof or target frontier with fewer currently exposed nodes, then source; this is a simple heuristic and not an exact partial-information oracle. Random seed fixed by case/budget. Oracle is a ceiling with complete graph information, not a competing actor.

## Evaluation
Verify every verdict certificate using SA-02's independent checker; report no unsupported verdict as success. Report correct, abstain, errors, false rejection, supported-vs-defect coverage, both axis counts, joint four-arm families, actual reads, and gap to minimum for correct verdicts. Primary learned gate: at 16 and 32 reads on fresh deeper cases, both recurrent seeds must beat every registered symbolic policy in summed certified verdict count across those two budgets by at least 4 cases, without any false verdict. Mechanism split and static model comparisons are secondary. If symbolic policies reach the oracle or the learned gate fails, preserve failure and investigate acquisition limits instead of modifying test results. All inference uses the same single-read interface; CPU time is recorded but read-budget matching is not CPU-budget matching.

## Limitations
All positive correspondence checks are definitional equality within a finite decidable fragment. The generator's proof dependency metadata is corroborated by selected root native axiom checks, not extracted from arbitrary Lean bodies. A real native audit will need explicit theorem statement comparison, nondefinitional bridges, axiom whitelist and a separate unresolved class.
