# RB-CG-04: counterexample-guided minimum premise repair

## Question and registered scope
CG-03's learned branch/repair gate failed; the first complete results are archived in its subtree. Its repairs were single omitted hypotheses. This follow-up tests minimal multi-hypothesis repair using the finite hitting-set equivalence in CG-03 REPAIR_THEORY.md. It is a finite semantic oracle abstraction, not a raw Lean parser or free-form critique model. The model chooses repair proposals; exact code constructs and verifies a scoped critique.

An original satisfiable finite theory entails a goal. Its weakened advertisement retains a hidden set W of countermodel rows. Every candidate omitted premise h is publicly represented by a bit mask of rows it excludes. Row 0 is an independently retained safe model excluded by no candidate. The complete original premises cover W. An auditor receives the candidate masks and public row count but learns W only from a charged oracle: propose R; return either UNSAT (no remaining countermodel) or a row in W outside the union of masks in R. For each family a fixed random row order resolves witness ties. This deliberately models restricted semantic access, not arbitrary Lean entailment.

## Prospective source
160 independently generated families, three arms each: already valid (W empty) and two weakened advertisements with distinct W, each requiring multiple premises. Train 80 families seed 104401, cal 16 seed 104402, deep 32 seed 104403, clutter 32 seed 104404. Deep uses 4–5 mandatory anchors versus 2–3 in train/cal/clutter; clutter has 12–16 decoy hypotheses versus 4–8. Each anchor is in W and each candidate excludes at most one anchor. Each group has two or more alternative candidates, including two that cover its entire group, giving multiple minimum repairs. Public row positions and candidate order randomized. Optional rows may be excluded from W; masks visible but no anchor annotations or generator family labels in policy inputs. Exact minimum is at least the number of anchors and attained by one full candidate per group. Native Lean 4.19.0 compiles original and reference repair bitmask coverage, safe-model exclusion and the anchor membership/at-most-one certificate. Native checks are bitmask statements for finite semantics; exact minimum is verified independently in Python using witnessed lower bounds. Validate fresh family and arm IDs, uniqueness and multiple optimal repairs.

## Policy
Start with empty proposal. Each countermodel yields a constraint that at least one selected premise exclude its row. Compute the exact minimum cardinality of a hitting set of all observed constraints, and enumerate at most 64 distinct minimum sets using deterministic candidate order. All policies share this identical exact proposal pool; its restricted tie enumeration is reported. Rank by lexical order, random (seeded per case), public union coverage, rarity-weighted coverage, and a learned scorer. A 16-hidden-unit MLP takes only features of public masks, observed rows, candidate set and remaining budget-independent state. Two seeds 91/97; 12 fixed epochs, AdamW lr .003, batch 64. Train on train-only traces from lexical and public-coverage policies at a 32-call cap, with a soft action-set target over candidates maximizing hidden W coverage; hidden W used only by teacher after collecting the pool, never by an inference actor. The actor cannot inspect hidden W or oracle fields. This is code-level access discipline, not process isolation.

Budgets 2/4/8/16/32 oracle calls including the initial empty proposal. Return a countermodel-backed refutation with witnessed lower bound if the budget runs out, or a minimum-cardinality repair when the proposed set covers W. Already valid cases accept empty repair after one call. A sound exact checker independently checks every observed row, candidate sufficiency, and infeasibility of a smaller hitting set for the observed constraints (bounded recursive feasibility search independent of the actor's enumeration). The lower bound plus sufficient repair certifies minimum cardinality; no oracle timeout establishes validity. Recompile distinct actor-returned sufficient repairs as native bitmask coverage theorems and check axiom output. Native proof does not independently certify minimality, which is the finite verifier's contract.

## Metrics
Report supported, verified refutation, minimum repairs, incomplete, false accusation, actual oracle calls, pool counts, and candidate enumeration search cost and CPU time. The unrestricted full-W minimum solver is an information-advantaged ceiling. Primary learned gate: on fresh deep and clutter at 4 and 8 calls combined, both learned seeds must exceed the best fixed symbolic policy by at least 6 complete minimum certificates, without invalid certificates. Report per-split and per-seed results; no test tuning. Any gain is relative to the common bounded pool and oracle; no claim of neural advantage over full information exact solving or wall-time equality. Record failed gates.
