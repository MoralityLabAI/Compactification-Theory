# RB-CG-11: elaborated proof dependency extraction and metered source critique

## Question
CG-10 uses a restricted generated dependency DAG. This follow-up obtains the actual declaration edges from the Lean kernel environment. A lexical occurrence is not necessarily a dependency: failed or unselected tactic alternatives and local shadowing can mention an unauthorized axiom without using it. Conversely, a theorem may use an unauthorized constant through its type or an intermediate definition. Audit the actual submitted term and its transitive axiom closure, not arbitrary semantic necessity.

## Source and native contract
Lean 4.35.0 pinned release. Generate 128 source families: train 64, cal 16, test_depth 24, test_syntax 24, seeds 111101/111102/111103/111104. Four selected declarations per module (512 cases); two clean, two tainted. The same source module provides a clean proof and a forbidden-proof branch of an identical P ∧ P target, plus two analogous equality-type chains (one type transitively uses a forbidden data constant, the other a permitted data constant). Both forbidden constants and permitted environment axioms are explicitly listed by policy. All declarations are valid Lean; no contradiction is introduced. Opaque identifiers and independent declaration ordering are randomized subject to dependencies. Chain depths 1–3 in train/cal/syntax, 6–9 in depth. Ordinary exact terms and unselected tactic alternatives are train mechanisms. Held-out syntax uses local shadowing of the forbidden/allowed names, and show terms. Dead declarations and decoy branches are retained.

A native command walks each selected declaration's elaborated kernel type and value, using Expr.getUsedConstants. For local generated declarations support axiom, definition, theorem and opaque nodes; abort on unknown local kinds. Treat other declarations as imported boundary nodes with Lean.collectAxioms summaries, not as axiom-free leaves. Export machine-readable root, node-kind, type edges, term edges and boundary axiom lists. The independently computed graph closure must match the complete Lean.collectAxioms root set and #print axioms outside the namespace. Native output supplies the graph; no generated reference DAG or lexical parser is substituted. Boundary proof-body provenance is deliberately abstracted at the axiom summary. All native roots compile, expected policy classification is checked, and exact graph logs, raw sources and hashes archived.

## Metered task
A session reads the selected root first and then only discovered dependency nodes. Each node read costs one unit; type and term edges revealed together. Public raw source, root name, explicit forbidden policy and declaration names are visible; full native graph, native labels, and boundary summaries are withheld from the actor until reads. A tainted certificate is a path to a forbidden axiom or an imported boundary whose exposed summary includes it. A clean certificate requires every reachable node read and all leaf axioms permitted. Verify paths and closure against exported graph, compare accepted verdict with independent native axiom closure, and report an unresolved search as abstention. The policy is relative to the supplied basis; a forbidden dependency establishes neither inconsistency nor falsity.

Controls: BFS, DFS, lexical name order, lexical risk (backward distances in a naive surface-token graph). Also report the standalone lexical classifier's unverified false accusations/misses; never release its guesses as verified critiques. Two 32-hidden-unit learned read rankers (seeds 161/167) train on train-only sessions, optimal shortest remaining path to a forbidden leaf or all frontier actions on clean cases; 15% exploratory legal actions, 12 epochs AdamW .003 batch64. Public lexical features and exposed path metadata only. No hidden node kind, future edges, verdict or generator metadata in policy input. Lexical analysis is free preprocessing shared by relevant policies; count reads, rank computations and CPU separately. Full-closure reference unbudgeted. Evaluate fresh 8/16/32/64/128 reads. Primary gate: both seeds gain at least six certified verdicts over best fixed control across both test splits at 16/32 reads, zero wrong verified verdicts. Report tainted and clean recall separately and matched lexical false accusation rate. No claim of arbitrary Lean kernel audit support beyond the stated local kinds and boundary contract, or free-form prose generation.
