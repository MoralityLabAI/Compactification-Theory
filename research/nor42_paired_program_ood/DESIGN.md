# NOR-42 paired program-grammar OOD: historical-source smoke gym (DESIGN ONLY)

[Research issue #229](https://github.com/MoralityLabAI/Compactification-Theory/issues/229) proposes paired clean and hidden program futures that agree on every publicly demonstrated output coefficient through degree D. The hidden future adds `β X^(D+32) T(F)`, where `β∈{−2,−1,1,2}` and T is one of the original unit-series operations `I,N,R,S`. For a normalized input series F with F(0)=1, each T(F) also has constant coefficient 1, so the first changed hidden future coefficient differs by exactly β at index D+32.

The mathematical information constraint is now kernel-verified in [MathCan PR #142](https://github.com/patrickdugan/MathCan/pull/142) at commit `748bddf39d868e9658d31aab0f3f5fa71ddadae8`. Any predictor that receives only the publicly common output prefix must issue the same prediction for both paired worlds, so it cannot be correct for both when β is nonzero.

## This branch's scope

This is a **historical-source-only smoke test** with an intentionally small CPU footprint. Every smoke input originates from the original, prospectively registered NOR40 archive `research/nor40_strong_adversaries/results/nor40_original_first_hosted.zip`, whose source and first grade were completed, independently replayed, SHA-pinned and merged on main before NOR42 design. The test imports only public NOR40 source rows and their already independently verified clean continuation; it creates no fresh NOR42 source identity, CAL/EVAL audit stream, attack support, registered scientific gate or private target for a future NOR42 study.

The `paired_model.py` implementation computes:
- The exact two future coefficient sequences with public-prefix identity, and `first_difference = D+32`.
- The complete discrepancy set S between clean and hidden futures. Its size is determined by the input and transform support.
- Exact full-output uniform k16 hit probability `1 - C(m-|S|,16)/C(m,16)` for an **independently authenticated** true target witness.
- The result of comparing the public inferred clean continuation against the hidden truth at a particular k16 checked plan. It is an illustration of a hypothetical authenticated witness, not a construction of one.
- An unauthenticated internal-consistency check that compares the clean proposal against the clean inferred continuation and consequently can accept even when the hidden true future differs. This illustrates why native grammar acceptance is a strictly narrower premise than target authenticity.

**Threat-model separation:** this paired clean/hidden target experiment probes extrapolation and witness availability, not the previous r4 malicious attack. For a future precommitted support A in the r4 attacker model, the optimal uniform-k16 bound from NOR38/MathCan has different parameters. Here the difference support S may include hundreds of coefficients and is generated by a latent program term rather than adversarial control.

## Before any prospective NOR42 experiment

A distinct registration must define the number of new pairs, observation degrees and input families, method for sampling β and T, the timing of public-only paired source freeze, and exact independent native interpreter obligations before drawing fresh new source identities. New paired sources must be disjoint from all archived NOR26–41 sources, including the first original NOR41 cohort once its grading archive completes. If experiments require a true future oracle, the source of that authenticated oracle must be specified separately from the public-output program inference. The first scientific FAIL remains evidence and must be retained.

This smoke branch may be merged as source-independent infrastructure while the future registered NOR42 study remains unstarted.
