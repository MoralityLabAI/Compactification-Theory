## Observational and authentication limits

Any deterministic predictor using only the common public demonstration output prefix and query input issues the same future prediction in both possible paired worlds. Since the hidden and clean futures differ, it can be exactly correct for at most one of the two. With equal-prior world labels, the pair-average exact full-output accuracy ceiling is **50%**, as shown formally by the [Lean NOR42HiddenSuffix theorem](https://github.com/patrickdugan/MathCan/blob/main/MathCan/NOR42HiddenSuffix.lean).

The witness-free checker that compares the public clean continuation to itself accepts it in both worlds. Its hidden-world **false-acceptance rate is 100% by construction**, regardless of whether the actual target has the hidden suffix. The paired-world authenticated verifier checks a synthetic true target whose coefficients are furnished by the generator after source freeze. In the hidden world, it rejects the public clean proposal when its checked set intersects the latent true discrepancy support; it accepts the true clean world without false rejection. This illustrates exactly which extra information a verified future-output oracle would need to provide.

**The experiment does not construct a real-world authenticated output witness**, prove its cryptographic soundness, or show that a verifier can learn unknown hidden ground truth without additional access. All SHA challenge schedules are public reproducibility fixtures rather than deployed hidden entropy. The latent hidden term is an artificial off-grammar program extension and should not be generalized directly to natural language or arbitrary learned recurrent dynamics.

The 64 source pairs, grouped into 16 replicate blocks of four, are the independent observation units. Repeated policy plans and the two possible target worlds are paired observations. The exact conditional uniform theorem is a finite-support combinatorial statement, rather than an empirical source-block hypothesis.
