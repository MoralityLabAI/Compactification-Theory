# NOR-42: paired off-grammar hidden futures and authentic output verification

[Prospective registration](REGISTRATION.md) was frozen in first commit `9bf353b7c76535e581ff026098cd682914a90ef0`, before any new NOR42 source or latent hidden program. [PR #235](https://github.com/MoralityLabAI/Compactification-Theory/pull/235) builds on [NOR42 design issue #229](https://github.com/MoralityLabAI/Compactification-Theory/issues/229), the [merged Lean theorem](https://github.com/patrickdugan/MathCan/blob/main/MathCan/NOR42HiddenSuffix.lean), and [historical-only 48-source smoke data](../RESULTS.md).

The first NOR42 source cohort has **64 fresh public-source pairs** indexed by 16 independent replicate blocks 100–115, two visible degrees D512/D1024, and two fixed input families: dense-original and 64-position regime blocks. It excludes **388** earlier original SHA source identities, including NOR41's first source-only fixture, graded scientific FAIL and permanent original ZIP. Each pair supplies identical public observed demo coefficients 0..D, the same full public query input and the same 16-class original RRC25 native acceptance mask in two possible true worlds. Its clean hidden-world competitor adds `βX^(D+32)T(F)`, with `β∈{-2,-1,1,2}`, `T∈{I,N,R,S}` and normalized `T(F)_0=1`. At the first hidden coefficient D+32, the future differs by β. The two futures cannot both be exactly predicted by any deterministic source-public-only predictor, which receives an identical input for both.

Five fixed policy laws preserve k16 exact output coefficient checks: **whole-output uniform16, original NOR31 mixture, deterministic curvature50 mixture, and primary global7_mix (7/16 whole-output uniform16 + 9/16 deterministic curvature)**. A fifth atom-random hybrid50 arm provides a diagnostic. All policies are configured from the inferred source-public *clean* continuation, before the hidden true target is restored. Each source has 1024 independently salted EVAL schedules per audit component. The first original grader records both true worlds separately and measures the ability of a hypothetical **independently authenticated true-output witness** to reject the clean proposal against the hidden target. The witness-free control compares the same proposal to its own inferred clean continuation and accepts even when hidden world truth differs.

The hidden difference support `S` may be far larger than the radius-four attacker support in NOR38–41. The exact hidden-world uniform16 discovery probability is `1-C(m-|S|,16)/C(m,16)`. Global7 retains the mathematical uniform-only detection contribution `(7/16)` times this exact value, conditional on actual hidden audit randomness. Neither the public SHA challenge streams nor the synthetic true-output generator establishes real-world deployed cryptographic authentication.

Five precommitted science gates are frozen for the first 64-source experiment: strict pairwise public transcript equality and future divergence, exact uniform16 calibration, authenticated hidden detection above self-consistency, global7 competitive detection against pure uniform on the new input family, and source-first/native/private witness/independent replay integrity. The registered original science score may PASS or FAIL. A FAIL remains first-grade evidence and must be archived unchanged.

The pre-data suite uses **only previously completed NOR41 source identities or synthetic inputs**, and an independent reviewer separately regenerates the historical source interpreter, plan construction and hidden-suffix rule.
