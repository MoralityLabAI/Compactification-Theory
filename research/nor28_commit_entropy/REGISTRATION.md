## Information and ordering

NOR-27 showed zero detection if an attacker chooses changed positions after learning the complete eight-coordinate random reserve. NOR-28 tests binding the changed positions before sampling fresh OS entropy and before any seed disclosure. A source-bound, randomly salted SHA-256 digest serves as the experimental attack commitment. Computational collision/preimage resistance, private stage separation, the OS random source and the authenticated exact-value witness are explicit external assumptions.

The stage order is mandatory:
1. PREP creates twelve new source-only RRC25 cases and public predictions. It prepares eight radius-four attack sets per source, writes their salted preimages into a sealed attack file, and publishes a separate commitment manifest with one SHA-256 digest per attack. The PREP artifacts are frozen and SHA-256 checked before the next job can begin.
2. CHALLENGE independently verifies original attack preimages and the manifest before drawing any audit seed. It then calls Python secrets.token_bytes(32) once, obtaining a new 256-bit OS entropy root, in a distinct GitHub Actions job dependent on successful PREP. It generates 512 schedules per source and auditor using keyed HMAC-SHA256 counter-mode with unbiased rejection sampling and without replacement. This root/schedule JSON is frozen and hashed before the sealed attack file is reopened for grading. The original root is disclosed afterward in the immutable evidence for independent replay. The logged job sequence is an operational ordering check, not a proof of trusted hardware randomness.
3. DISCLOSURE gives the attacker views containing zero, eight, sixteen or all 256 high bits of the root AFTER attack commitment. All four views concern exactly the same already committed attack and realized challenge schedule. They must produce exactly equal detection decisions, pathwise. A separately labeled **counterfactual timing-violation attacker** chooses changes in four unchecked positions after seeing the actual complete schedule; it evades every audit but cannot open the earlier public commitment. Allowing a new commitment after disclosure illustrates the ordering failure.
4. AUDIT independently restores source-only proposals, commitment openings, entropy-derived schedules, honest target values and every detection decision. No production cryptographic security claim follows from replaying publicly disclosed research bytes.
