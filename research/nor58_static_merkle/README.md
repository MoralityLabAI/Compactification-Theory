The [indexed static template](template.py) uses only original NOR45 domain tags, original full length and original leaf index for each hash. It precomputes only fixed off-support zero leaves, power-of-two padding leaves and entire internal subtrees containing only such fixed leaves. Each template is immutable and keyed only on independently trusted full length and exact support stride. It never caches an accepted full root, dynamic supported coefficient hash, prior signed witness or session. Every supported coefficient is rehashed from the new signed witness on each verification.

The [common signed verifier](verify.py) shares the same source-bound Ed25519 research-signature validation, trusted original source and session, monotone verifier nonce/replay guard, canonical compact-v2 decode, original full coefficient and packing caps, and NOR53 exact signed GMP reduced identity. Every arm returns the identical complete signed integer inverse vector and full original Merkle root, independently checked before timing against NOR56's signed-v2 verifier.
