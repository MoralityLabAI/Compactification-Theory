# NOR-35: equal-atom-budget curvature-targeted exact witness auditing

**Registration frozen before data:** [REGISTRATION.md](REGISTRATION.md), first applied commit 3773c1b on November 17, 2026.

NOR-34 showed that original NOR25 auditors' eight public tail/magnitude/lag membership categories explain nearly all of the curvature attack support localization advantage. NOR-35 changes which coordinates are inspected *within* each of those fixed old atoms, holding every source/trial/auditor original inspected quota identical.

Four exact k=16 transformations of each original NOR25 audit policy are compared: original, atom quota-matched random sampling, deterministic highest-curvature selection for half the quota with randomized remaining positions, and an inverse lowest-curvature control with the same 50/50 targeted/random budget. Frozen NOR31 weights [2,0,1,1,4,8]/16 are applied to original and transformed constituent policies separately. All public curvature scores are computed from the original exact public query prediction; neither hidden generating program nor authentic true target coefficients are used when designing audits.

Source-isolated prospective TEST comprises 24 new original RRC25 public-only problems with replicate IDs 48–51 at degrees 512/1024 and all three wide input families. Historical source digests from NOR26 through NOR34, 108 cases, are SHA-locked and excluded.

Four source-public alteration laws fix 16 radius-four attack sets each *before* 512 independent challenge schedules per source/arm: high curvature in the old historical union and its complement (2+2 changes), low-curvature inverse support (2+2 changes), quota-matched attack redraw from full eight atoms, and full-uniform random attacks. Full native exact integer witness verification under both nonzero alteration magnitudes and fully informed schedule-visible zero-detection controls remain in place.

The registered PRIMARY uses exact conditional hypergeometric probabilities averaged over frozen challenge schedules, rather than judging the first 16 sampled attack sets as independent sources. The five success gates compare curvature reranking against atom quota-matched random, original hybrid50, inverse-curvature cost, transfer through NOR31 mixture, and mandatory atom-count/source/witness/full separate-process replay integrity.

**First valid registered outcome: PASS on all five gates.** The fully green [Actions #44064368383](https://github.com/MoralityLabAI/Compactification-Theory/actions/runs/44064368383) registered 24 new source-distinct public RRC25 cases, ran exact k16 audits across four source-public attack laws, and independently reconstructed 18,874,368 policy/attack decisions. High-curvature targeted half-plus-uniform auditing detected **35.87%** of curated top-curvature changes versus **19.14%** for an eight-atom-quota matched random audit, a **+16.73 percentage-point** gain across 24/24 source units. The original hybrid50 scored **19.15%**. Reweighting all six frozen NOR31 policies with within-atom curvature gave **34.81%** versus the old mix **15.20%** (+19.62 points). The redesigned auditor paid a **−2.14 point** low-curvature support cost versus atom random. Eight-atom quota-matched attack expected detection and whole-output uniformly sampled attack expected detection remained exactly equal across rerankings. All 24 source pairs met every frozen threshold.
