# ARG-02: Qwen / looped-layer execution workorder (unrun)

This is a prospective, optional GPU experiment. The current CPU run used the frozen 6,240-weight RRC-19 task-trained GRU. A Qwen graft cannot be asserted from that evidence.

1. Freeze model repository, exact resolved revision, quantization, tokenizer, software stack, device name/VRAM, source/adapter hashes and the actual recurrent computation site. `model_revision` in `external.py` must be the resolved 40-character git commit SHA or SHA-256 digest of local checkpoint bytes. Record the first/last forward activations and real loop count per case; a declared depth alone is metadata.
2. From the pinned EvalMath checkout, export the public 192-case test/control set. Train or tune only on the separate 36-case calibration roster or an independently generated training roster; record generator seed, contamination audit and total GPU-seconds. Hold out all test cases from learning, prompt tuning and early stopping. Treat prior RRC-19 tests as exposed development context.
3. Run Qwen/looped model with latent refinement depths 0,1,2,4,8. Keep the same problem text, output grammar, decoding temperature, exact candidate budget, and information access in each arm. Add a same-parameter feedforward control, shuffled latent state and equal-token text-CoT control. Include untouched base-skill retention tests.
4. Log JSONL proposals with `case_id`, `public_sha256`, `depth`, `program`, actual `model_revision`, `inference_ms`, `generated_tokens`, and `model_forward_calls`. Never include future coefficients, labels, verifier answers, or hidden source graph in a model prompt. Use the exact oracle only after each proposal and charge candidate checks; if any residual is fed back during an iterative run, record and account for it as extra compute.
5. Evaluate accepted exact programs, withheld future-correct predictions, bad/abstained outputs, p50/p95 wall time, total neural forward MACs or FLOPs, CPU verifier work, peak GPU memory, held-out source-family splits, paired success counts and retention drift. Genuine depth effects require causal ablation of intermediate states, beyond resubmitting a program to a host interpreter.

Stop on altered checkpoint hash, invalid decoder contract, source/test overlap, unverified hidden-state hooks, or changed test prompts. This workorder spends no rented GPU time automatically.
