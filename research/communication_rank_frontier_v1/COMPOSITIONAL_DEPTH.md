# Compositional retrieval: degree and local-read lower bounds

For a nonempty set S of d independent bipolar memory coordinates, let f(x)=s prod_{i in S} x_i, s in {-1,+1}. Under the uniform hypercube measure the Walsh characters are orthogonal. Every polynomial p of total degree <d reduces on the cube to a multilinear combination of characters of degree <d, so E[f p]=0. If a threshold at zero (ties positive) computes f exactly, then fp>=0 everywhere and fp>0 on the nonempty negative class. Thus E[fp]>0, contradiction. The polynomial threshold degree is exactly d because f itself is a degree-d polynomial. This includes a static affine head of any rank when d>=2. This is a representational lower bound, not a bound on approximate classification accuracy.

In a deterministic coordinate-query model, each local pass may inspect one memory coordinate, with arbitrary computation on the previous observations and a fixed query program. Exact parity on d distinct coordinates requires at least d reads on every path: if a relevant coordinate has not been inspected, flip it while fixing all inspected coordinates; the full transcript stays identical and the target changes sign. Signed conjunction on d distinct literals requires d reads on at least the all-satisfying input by the same flip argument. Both lower bounds are attained by a serial binary accumulator, starting at +1 and applying multiplication (parity) or minimum (conjunction) with each signed literal.

One-hot masking of a shared identity component bank produces a rank-one linear write per pass. The full bank still has rank k, local persistent memory contains k bits, and program metadata includes the address mapping, selected indices, signs, operator and clock. Neither the one-bit accumulator nor the active rank implies rank-one total storage. The distributed protocol uses q=log2(k) bits for the injective query address and one reply bit; local coordinate reads are not messages. This theorem does not apply to a dense learned projection that mixes coordinates in one read, arbitrary nonlinear encoders, or an unrestricted recurrent state.

LOGRANK-BPD-07 learns programs by exhaustive finite dictionary scoring, with a strong prior over signed parity and conjunction of arity <=3. Full-depth exactness follows from canonical program equality; it is not a consequence of sample accuracy. A Lean formalization remains future work.
