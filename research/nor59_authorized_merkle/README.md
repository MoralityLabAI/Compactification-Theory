# NOR-59: source-certified static Merkle roots for genuinely signed NOR45 executable programs

The [first prospective registration](REGISTRATION.md) was frozen at **8f6eb3dccc4d4c4d9d58955387ea6f154ad05d84**, before any NOR59 public source or signed-authorized CPU timing. It follows the immutable NOR58 5/5 PASS on algebra-only reciprocal witnesses, while adding NOR45's real authority-signed exact program grammar and NOR44's original verifier precommit and provider reference signatures.

The added [support-closure checker](authorized_root.py) derives the greatest supported stride of 8, then 4, else 1 from the independently supplied complete normalized public query. Its accepted input has length m769/m1537 and observed D512/1024; each original NOR45 program is independently authenticated and validated under the unchanged exact program grammar. The allowed delays 64/80/96/112, spacings 24/32, and optional D+32 hidden suffix shifts are all divisible by eight. The unary operations I,N,R,S retain support in the original source stride, since S doubles indices and the unique inverse of a normalized supported formal series retains its support. Before use, the integration checks **every recomputed full output coefficient** outside that independently determined support is zero.

[Original NOR45 verifier](../nor45_authorized_program/independent_execution_verifier.py) still runs unchanged signature/context/program checks, exact NOR45 interpreter and original full output root when called with its default `_root_policy="original"`. The two explicit internal policies `warm` and `cold` call NOR58's original-indexed Merkle template only after every NOR45 program-authority signature, NOR44 verifier precommit, NOR44 provider reference, signed statement source and full query digest has been checked. No arbitrary user root callback or caller-provided template is exposed. Warm cache entries are internally generated from original full geometry alone, keyed only by trusted (m,stride), and never include a prior full root, dynamic leaf, source witness or session. Cold builds the same geometry-only template inside the timed signed call. Every supported coefficient is hashed fresh and the full NOR45 Merkle root must equal both authenticated certificate and original provider reference.

The [source-free signed tests](test_authorized_root.py) exhaust original allowed degree/source stride/profile combinations under toy inputs, check original index-specific padded and output hashes, compare complete original/warm/cold authorized full signed vectors and Merkle roots, and reject forged source/query, provider signer, program authority, verifier signing key, nonce/session, wrong output root, hidden offset, malformed exact program and explicit unknown root policy. Both original NOR45 and NOR44 security tests remain unchanged. The code documents the missing Lean kernel proof and the explicitly public deterministic research signing keys.

The fresh [60-source/prog first roster](cohort.py) uses NOR59/SOURCE/v1 and a fixed 2 observed degrees × 3 strides × 5 authorized program profiles × 2 independent sign replicates. Every source identity is disjoint from all 528 original first NOR51–58 sources through SHA-pinned archived ZIPs. Only public source/program descriptions are frozen in the upstream first SHA job; no output, hidden target, Merkle root, certificate, nonce, signature, precommit, template or timing occurs upstream.

The [three-arm CPU study](benchmark_cpu.py) runs five source-and-repetition-seeded interleaved complete NOR45 program verification samples per arm on one pinned Ubuntu24.04 Python3.12 host with original research Ed25519 fixture keys. Each arm consumes the same signed program statement, NOR44 verifier precommit, signed provider reference, trusted source and unique session nonce, recomputes the exact same complete NOR45 program output and returns its original full Merkle root. Outside timing, the benchmark constructs an independent original full output/root oracle, five prebuilt signed sessions, and six geometry-only warm templates, reporting their costs separately. Original full Merkle, warm static template and cold static template are the three timed policies. One root-only diagnostic per source occurs strictly after all original whole-arm timings.

Five frozen original engineering gates are: on all 40 sparse s4/s8 authenticated program cases, warm/original signed whole verifier median <1.02; on the same 40, root-only template/original median <0.70; on 20 dense s1 cases, cold/original full signed verifier median <1.25; 60/60 complete authenticated program output/full original Merkle root parity and malicious authority/session/source checks; and source-first SHA/528 old-ID exclusions/five exact repeats/geometry-only cache/byte-identical first evidence archive. Any first FAIL remains original and requires independent follow-up.

**Limitations:** NOR45's signed program execution is faithful only to the *authority-selected* program under externally trusted authority/source semantics. Original NOR44 verification is stateless across independent authenticated calls; repeated identical bundles require deployment-layer nonce-state management. The reference keys and nonce fixtures are publicly reproducible and unsuitable for deployment. The fully signed original NOR45 grammar supports m769/m1537, while NOR58's m3073 results were algebra-only. The output is transparent and nonsuccinct, with no zero knowledge or machine-checked Lean support proof.
