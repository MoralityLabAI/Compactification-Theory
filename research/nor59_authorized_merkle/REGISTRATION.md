## Exact authenticated-program support closure

The original NOR45 grammar accepts observed degree D∈{512,1024}, complete output length m=3D/2+1∈{769,1537}; base,u,v,optional hidden transform from I/N/R/S; allowed program delay k∈{64,80,96,112}, spacing t∈{24,32}, amplitude ±1/±2, hidden_beta=0 or ±1/±2 and optional hidden shift onset D+32. These k, k+t, k+2t and D+32 shifts are all divisible by 8. For independently observed normalized exact integer public source F(x)=H(x^s) with s=4 or 8, I,N preserve support, R has exact supported inverse, S has support in 2s and hence s, integer scalar multiplication and additions preserve support, and all allowed shifts preserve support. Therefore every **exact authorized** output has zero coefficients at original indices not divisible by s.

The cache route derives the **maximum allowed support stride s=8, then s=4, else s=1 from the independently supplied full public query**. It never accepts a caller/provider/program/model-claimed sparse stride. The derived stride must agree with every full input/source coefficient and every **recomputed** authorized output coefficient. The already authenticated program must pass NOR45's **unchanged** grammar checker; the code separately verifies that k, k+t, k+2t and optional D+32 are divisible by the selected s. An unsupported or semantically ineligible source/program takes the original full Merkle route or is rejected by the original NOR45 validator; no unverified template is ever applied. The exact root still uses NOR45's `LEAF`, `PAD`, `NODE`, uint32 original full length/index framing and canonical signed integer encoding, while NOR58's immutable static template caches only index-specific zero/pad leaves and static-only subtrees keyed by trusted (m,s). All supported output coefficient hashes and dynamic internal nodes are computed from scratch on each verification. No accepted output root, prior witness, model-supplied hash or signed session value is cached.

## Security and formal scope

This experiment tests original NOR45's actual **m769/m1537 authorized signed-program grammar**, unlike NOR58's algebra-only m3073 transparent inverse benchmark. All fixture Ed25519 signing private keys and deterministic synthetic source data are public, **unsuitable for deployment**. The full execution verifies a signed authority-selected program conditional on honest external program authority and independently trusted source; it does not prove that the authority selected a true-world program. No succinct or zero-knowledge proof follows. A future Lean/MathCan kernel proof should formalize support substitution and finite inverse uniqueness, the shift/operation closure of the actual grammar, and extensional equivalence of original indexed Merkle hash trees with static subtrees; Python tests and hosted CI alone are not machine-checked proofs.
