### Routing and threat model

The routing key is the **independently verified, authorized native program statement**. Select GMP inverse-trace verification if any of base/u/v/active hidden operation equals `R`; otherwise choose the original NOR45 exact direct execution. Every arm reconstructs the full exact integer future and full output Merkle root. The auditor's pinned program authority, verifier-signed precommit, nonce/session, provider-signed reference root and k16 queries must be checked by the existing NOR44–46 authenticated acceptance path before this benchmark-only arithmetic core is considered meaningful. Never use untrusted model output, claimed trace content, timing data, proposed future, or an unsigned backend hint to dispatch.

The **NOR48 GMP branch must be reentrant**: implement a local, independently inspectable exact NOR46 trace validator with an explicitly passed GMP convolution function, preserving signed-integer/no-carry bound, original full trace schema, per-op checks, source query hash, program grammar, and all output coefficients. Avoid process-global monkeypatches or mutate the older NOR46 verifier in runtime production code. The NOR45 direct branch ignores any attacker-supplied trace. This branch is a research arithmetic+root comparator and does not claim to provide a production signed end-to-end API. Preserve full signed-source attacks and root checks in separate tests.

### First original fixed benchmark

- Five same-run interleaved repetitions for each of **NOR45 direct**, **NOR46 original Python packed trace**, **NOR47 GMP packed trace**, **NOR48 authenticated-program R-aware dispatch**; same 16 frozen source pairs; same precomputed, untrusted trace on trace arms. Include complete exact output vector and independent Merkle root construction in each measured arm. Signature, transport, and session verification costs remain excluded **equally** from all arms, since they are checked in the unchanged historical authenticated control suite.
- Pin `gmpy2==2.3.2`, record Python/CPU/hardware metadata, memory cap and each individual timing. Sourcewise median dispatch/direct ratio is the registered engineering metric, with target **less than 0.75×**. All four original no-R programs must dispatch to NOR45 direct and match root. All 12 R programs must dispatch to locally injected GMP trace. A FAIL is a valid performance result and must remain archived byte-for-byte.
- Publish by-R sourcewise speed ratios, four-block descriptive intervals, exact GMP/direct/root equality, and negative cases for wrong signed program, source, root, tampered R coefficient, truncated trace and unsigned model-selected backend flag.
- Preserve the original first NOR48 CSV/JSON and independent digest; no change in source selection, backend routing, first repeat count, registered benchmark threshold, or test verdicts after first timing. A bigger source cohort requires separate registration.

Conditional security premise: an authorized, honest publisher signing the intended native program, a separate trusted target provider, and computational security of Ed25519/SHA-256 remain external. This is **transparent, nonsuccinct** exact execution, not a ZK proof, and the test fixtures contain public test keys.
