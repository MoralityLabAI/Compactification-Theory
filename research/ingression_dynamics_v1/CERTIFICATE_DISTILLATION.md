# QO-14: Distilling certificate-reachability into a tiny trained RNN

**Protocol fixed 2026-11-04 before completing the experiment.** Builds on [QO-13](CERTIFICATE_REACHABILITY.md). The target is the exact two-probe probability of obtaining a valid feasibility certificate using the existing QO-07 confidence evaluator. This is a synthetic CPU-only experiment with **two known resettable transient states, one action and one absorbing goal**. The confidence-sequence theorem and IID/addressability requirements remain unchanged.

## Exact teacher and bounded neural students

For public evidence E containing only observation counts, hits, and nested confidence intervals, the two exact action labels are

\[
Q_2(E,c)=
(1-\widehat p_c)V_1(E^{c,0})+
\widehat p_c V_1(E^{c,1}),\qquad
\widehat p_c=(s_c+1)/(n_c+2).
\]

V_1 chooses the best second action after the first observation. Exact Fraction labels are generated with QO-07's true interval-update rules and checked against the original QO-13 Bellman solver. The Beta predictive is used only for **planning**. Actual validity of the resulting feasible/infeasible certificate comes from QO-07's separate anytime e-process.

Each addressed cell is encoded as a six-number token: normalized observation count, smoothed observed hit frequency, confidence lower/upper endpoints, confidence width, and center offset. The *true* Bernoulli simulation parameter is excluded.

Two models are trained on these exact action values:

- **Linear student:** two sigmoid heads on 12 flattened public features, 26 trainable parameters, 24 multiply–accumulates per inference.
- **Recurrent student:** eight-neuron tanh RNN with trainable input, recurrent and output matrices. It has 138 trainable parameters, 240 multiply–accumulates per inference, 16 tanh evaluations and two sigmoid evaluations. Full two-step BPTT updates the recurrent matrix itself.

Both use source-fixed Adam, 65 epochs, learning rate 0.012, gradient clipping and seed 20261104. A predeclared weighted squared error emphasizes examples with positive Bellman values or differing action values. **Only validation loss selects the checkpoint.** Existing already-certified examples are excluded because their future-action choice is irrelevant.

The implementation uses only the Python standard library; finite-difference tests independently verify the BPTT gradients. Prediction outputs are trained probabilities, **not confidence sequences**.

## Independent splits and paired digital evaluation

Train, validation and supervised test splits use distinct predeclared Bernoulli rate families and random seeds; they are generated by three public sampling schedules and ten fixed evidence checkpoints. The policy evaluation uses six held-out test rate families with an additional independent seed set (1301, 1307, 1319).

The four policies are unchanged QO-08 **bottleneck**, trained **linear student**, trained **RNN**, and the exact QO-13 **horizon-two teacher**. All observe the same per-cell Bernoulli stream prefixes and consume identical budgets. Teacher and students use the same readiness requirement of eight observations per cell, and fall back to bottleneck when already certified or their highest predicted acquisition value is below 0.05.

Registered policy checkpoints: **32, 56, 80 queries**. Six rates × three seeds × four policies yields **72 trajectories, 216 checkpoint records, and 5,760 Bernoulli queries**.

The model receipts preserve validation-selected complete weights, train/validation curves, held-out test action-value accuracy and teacher action regret. Policy receipts preserve every feasible, infeasible and unresolved decision, true one-step macro-model error, confidence coverage failure, false certificate, exact teacher calls and student inference multiply–accumulate counts. No performance-based test filtering or model choice is allowed.

A source-SHA-256 [result](../../results/certificate_student/receipt.json) is generated and checked byte-for-byte by [the verifier](../../scripts/verify_certificate_student.py). The first GitHub run emits the expected complete result. Its receipt must be committed unchanged and pass current-head CI before the PR may merge.

## Limits

The exact teacher solves a **two-probe** problem; its selected action need not optimize the entire 80-query evaluation budget. The recurrent student has learned weights, but this remains a tiny public digital benchmark. It has no demonstrated generalization to Qwen, BitAgent, biological morphogenesis, or hidden-state POMDPs. Model description, teacher data generation, and per-query planning costs must be charged when evaluating compute efficiency. Wall-clock latency is not a deterministic output and is outside the source-hashed receipt.
