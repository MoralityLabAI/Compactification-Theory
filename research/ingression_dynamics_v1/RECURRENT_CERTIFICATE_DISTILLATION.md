# QO-14: Tiny recurrent readout distilled from exact certificate reachability

**Protocol fixed 2026-11-04 before the first complete evaluation.** This follows QO-13's negative finding for exact gated finite-horizon Bellman planning. The target here is cheaper action selection through supervised approximation of the QO-13 *first-action* Bellman values.

## Teacher and disjoint data families

The teacher is QO-13, horizon 2, exactly two named resettable Bernoulli microstates, one action, one transient macro class, tolerance 1/5, confidence alpha=1/20 and 10 outward-rational bisection steps. It exposes exact first-action Q values, and their maximum must equal its predicted optimal value.

The [source-frozen dataset](recurrent_teacher_data.py) declares eight training Bernoulli rate pairs, six **different** test pairs, 12 training seeds, seven disjoint test seeds and nine count-pairs. The resulting **864 training** and **378 held-out** evidence states are generated by interleaving independent per-cell Bernoulli event streams. Inputs contain only past QO-07 observations and confidence interval information. Hidden true rates enter exclusively the generator and post-run audit. Every state is retained, including value-zero, tied-action and already-certified states.

## Learned model and control

The [reservoir student](recurrent_probe_student.py) uses a 24-unit tanh recurrence over two per-cell evidence tokens. Its input and recurrent matrices are **fixed random weights**; only its two-output linear ridge readout is trained. This is a **recurrent reservoir encoder with a learned readout**, rather than end-to-end recurrent-weight training. The matched control is flat linear ridge regression on the same evidence features and exact teacher targets.

The student predicts the two action-specific Q values. It chooses the higher-valued cell only when the maximum prediction is at least 0.07 and the action-value difference exceeds 0.005; otherwise it falls back to the unchanged QO-07 bottleneck selector. The exact horizon-two teacher follows identical gates. These thresholds were chosen before the experiment and are not a confidence calibration theorem. The QO-07 anytime e-process remains the sole authority for feasibility/infeasibility certificates.

## Frozen tests and cost ledger

- Held-out Q-value RMSE, value RMSE, positive-value-only RMSE, exact-teacher first-action regret, and accuracy restricted to states where the teacher's first-action values differ. Count all zero targets and ties so a degenerate zero student is visible.
- Paired rollout on the first four held-out rate pairs, seeds 809/811/821/823, budgets 24, 64 and 96, using four policies: bottleneck, linear, recurrent reservoir, and exact QO-13 teacher. Per-cell Bernoulli prefixes are identical for all policies on a given case and seed. Keep all unresolved states, confidence-coverage failures, false certificates and signed differences.
- Full trained weight checkpoint and data-source SHA-256 hashes, Float32-equivalent parameter bytes, estimated scalar MACs for the student, and exact QO-13 gap/branch evaluation counts for the teacher. Report runtime separately when measured; MACs alone do not imply energy or latency results.

The source-bound verification script reconstructs training, the checkpoint, held-out evaluations and every paired rollout on CPU. Final-head GitHub CI must pass bytewise before merging. No paid API, GPU time, real biological data or learned large-model transfer enters this experiment.

**Reproduction:** install NumPy 2.3.5, set OPENBLAS_NUM_THREADS=1, and run the QO-14 unit tests plus the receipt verifier described in the repository workflow. This follows established reservoir/echo-state ideas applied to a small verifiable decision-control contract.
