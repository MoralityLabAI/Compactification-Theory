# NOR-53: native GMP pack/unpack exact signed integer verifier

The first [source-first preregistration](REGISTRATION.md) is frozen in commit **ae56f414251a8485d127fc8f9899a24237870adf**, before any NOR53 source identity generation or first timing. It follows the [NOR52 immutable original 5/5 PASS](../nor52_sparse_inverse/RESULTS.md), where the separate untimed GMP phase ledger attributed approximately 49% of measured phase time to repeated integer packing and 40% to digit extraction/shifting.

The [native fast kernel](fast_kernel.py) substitutes gmpy2.pack/unpack for the two repeated Python-space large mpz shift/accumulator loops in NOR47. It keeps the same exact integer no-carry resource bound, offset, single GMP multiply and signed correction, returning every coefficient exactly. The public 2.3.2 pack/unpack order is checked against an independently computed exact integer. The [source-free tests](test_fast_kernel.py) compare raw packed integers, decoded digits, full signed convolution, all computed roots and 4097-bit hostile toy vectors against the existing NOR47 kernel. They test incorrect unit, noninteger, invalid length, wrong signed witness, false claimed stride and off-support witness/source mutations. Original NOR52/51 archived evidence and NOR50 signed-program/security controls remain unchanged.

The new [public-only 60-source fixture](cohort.py) uses a different SHA-seeded domain from NOR51/52 with the identical 2×3×5×2 factorial layout: observed lengths 769/1537/3073, dense 2-bit and sparse 2/8/16-bit source profiles and two sign families. All 60 public IDs exclude the 108 original NOR51/NOR52 IDs by source-controlled ZIP SHA. The first prospective workflow must generate and upload this fixture **before** a separately dependent first CPU job executes.

The first [benchmark](benchmark_cpu.py) uses four whole-integer+full-original-Merkle-root execution arms, each repeated five times with source-seeded interleaving: existing full NOR47 GMP, new full native GMP pack/unpack, existing NOR52 compressed GMP, and new support-checked compressed fast GMP. It independently computes the same full native inverse witness once before timing, recording its generation time, JSON witness size and serialization costs separately. The GMP verifiers all validate the full provided witness. Source/resource parity and no global verifier mutation are mandatory.

Frozen first engineering thresholds: pooled full GMP speed ratio <0.70 on all 60, high precision m3073 <0.50 on eight cases, compressed native-pack versus original compressed GMP <0.85 on all 48 sparse cases, complete exact output/root/tampering controls, and first-source identity/archive reproducibility. All five are required to pass. The first raw CPU/source receipt must be preserved regardless of result; post-hoc subgroup and workload analyses cannot alter its score.

This is an algebraic transparent exact full witness test on synthetic public input series. It does not expand the NOR45 authorized signed native grammar at length 3073 or imply a zero-knowledge or succinct proof.

The source-free CI suite runs on all ordinary PR pushes. The first source-only/CPU benchmark is activated by a distinct `NOR53-FIRST-CPU` commit after those tests are green.
