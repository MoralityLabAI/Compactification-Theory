# SG-01: Euclidean spectral geometry of shared information (v0.1)

Source: [OpenAI preprint](https://github.com/openai/math/tree/main/preprints/Euclidean-geometry-in-the-asymptotic-spectrum-of-tensors-November-24-2026). The paper's tensor spectral point is a compatible monotone semiring homomorphism. This pilot uses only the stated diagonal/wire formula and elementary convex geometry. We do not construct the spectral point or prove the paper's existence theorem.

Run `node research/spectral_geometry_v1/gym.mjs > sg01.json` from the repository root. No packages, GPU, API, or external data. The archived JSON contains every root and every arm. Synthetic features occupy subsets of eight fixed 2D sites; the price for independent exact discrete labels is the sum of half-hull-perimeters times log2 alphabet size. The 2D implementation is exact in formula, floating-point in evaluation. Integer line tests are exact within JS safe integer range. Gaussian width uses paired projections. Independent fan-out costs L(L-1)/2 and shared collinear labels cost L-1; an adjacent chain also costs L-1. Width is a resource proxy rather than a latency, mutual information, activation-rank, or hardware bound.

## Synthetic design and evidence boundaries

Two explicitly designed worlds: budgeted log utility depends on -1.45 log(width+0.25); null log utility has no geometric term. 64 training and 64 fresh synthetic evaluation roots per regime; 128 signs per evaluation root. No claims of generalization to neural models. Each arm picks three orthogonal one-bit components; patch displacement squared = 12. Matched sham moves three independent unused nuisance coordinates by the same magnitude, leaving the readout unchanged by construction. The generator exposes a noisy local readout proxy, energy, persistence and cosine surrogate. These are toy comparators, not implementations of native BPD or SVD; energy ranks singular values only for orthogonal features with diagonal covariance. Oracle ranks true squared weights. Both learned arms fit identical ridge procedures; geometry adds one feature; shuffled width tests pairing dependence. Root-level descriptive bootstrap (2,000) is for the primary capture difference; all other endpoints descriptive. No EvalMath READY or confirmatory p-value. Both regimes and all arms reported. Scope: exact finite arithmetic and designed synthetic pilot only. Test roots in this receipt are exposed and must never become confirmation roots.

SG-01C/F native handoff: freeze normalized sites independent of outcomes, explicit producer and consumers, candidate subspaces, and bit budgets; use a separate dev set to measure clean/corrupt/patch/sham task effects at matched actual displacement.
