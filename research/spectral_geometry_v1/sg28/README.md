# SG-28: exact last-use disjunctions for integer routing certificates

## Derivation

For each component j, restrict the last consumer index l to an interval [a_j,b_j] contained in 0..T, with l=0 meaning no read. For a fixed rational multiplier eta=e/D, the best relaxed contribution at l>0 is u_lj-eta_l+sum_{i<l} max(0,u_ij-eta_i)-lambda*b_j*(x_l-x_0); include zero iff l=0 is allowed. Here b_j in the price denotes the assigned bit cost, not the upper interval endpoint. Sum the exact component maxima and eta*k, then take mathematical floor (including negative objectives). The result bounds every integer schedule in the node. Computing it takes O(d*T) prefix arithmetic. A split at c replaces one interval [a,b] by [a,c] and [c+1,b], exactly partitioning its feasible schedules. A tree's maximum finite leaf bound is an upper bound on the root optimum. Keep all unresolved leaves at cap exhaustion; no proof depends on a numerical LP/MILP status.

Exact infeasibility leaves use a row-capacity witness (fewer eligible labels than the row quota), or an interval Hall witness: more labels with positive lower last-use bounds and their entire last-use windows within [a,b] than the sum of read quotas in that window. Each such label must occupy a distinct row slot inside the window. Both witnesses are independently rechecked. When last uses are all fixed, choose each required last-use read plus the highest-utility eligible earlier reads at each row; this optimizes the restricted schedule exactly. Numerical proposals for integral retention variables also permit this recovery without trusting numerical read values.

The optional canonical last-use LP uses y_i<=h_i, h_(i+1)<=h_i, h_i-h_(i+1)<=y_i, and 0<=y,h<=1, with h_(T+1)=0. Per-label this is the convex hull of true binary suffix retention histories: interpret h_i-h_(i+1) as probability of last use i, with mass 1-h_1 for unused; the required read at last use contributes h_i-h_(i+1), and optional reads before the last use fill the remainder of y_i, bounded by h_(i+1). Conditioning fixes h_i=1 up to the lower last-use bound and h_i=0 after the upper bound. Coupled row equalities can still create an integrality gap. Negated numerical row-budget marginals propose rational multipliers, and optional MILP makes only h integral. Reconstruct a legal integer schedule from the returned last uses, checking row quotas and scoring with exact integers. No floating solver objective, optimality status, or infeasibility status is accepted as evidence. On numerical failure retain an existing valid multiplier, split another interval if allowed, or return a valid open interval. The priority queue expands the largest bound; choose an unresolved fractional h nearest 1/2, deterministic ties, widest interval fallback. The recorded proof is a full partition tree; all leaves carry a checked rational upper or exact infeasibility witness. Independent replay enumerates the allowed last-use choices with an explicit positive-prefix sum, rather than using the producer's recurrence. Trusted in-process research code, not an adversarial execution/deserialization boundary.

The standalone cap-63 run closed 18/18. Separate four-arm comparison on those same exposed fresh tasks uses one common SG-17 chain LP, SG-20 feasible recovery and exact rational root bound as shared preparation. Measure common preparation once per task, add its process CPU to each arm. Root-only stops after preparation; MILP arm permits root LP reoptimization but no split (cap 1); tree uses cap 63 with MILP, and tree_no_milp uses same cap without MILP. Randomized order for arms after shared preparation, one measurement per task; independent proof replay excluded from timing. No matched hard CPU cap. All four close 18/18; root-only is fastest (9.813 ms vs 11.239 MILP, 11.256 tree and 11.173 tree_no_milp). Extra machinery is unnecessary for this random cohort.

12 deliberately planted integrality-gap tasks: disjoint triangle-cover groups g=2,3,4,5, retention price c=1,2,3, one read per visit, positive utilities 10 on two eligible labels per visit, -100 across groups/other labels, all consumer coordinates equal one. Any negative read loses 110 utility relative to a positive one, exceeding the maximum total retention saving for these parameters, so the optimal schedule uses eligible reads only. Each triangle needs two labels integrally; half-activation of three labels is a fractional feasible chain-LP solution costing 1.5*c. Summing each triangle's three cover inequalities gives matching lower cost bound; the global LP optimum is 30g-1.5cg, integer optimum 30g-2cg. These are designed stress fixtures, not random native data. Both tree arms close 12/12; root-only and MILP-only close 0/12, mean gap 3.333. The proof trees use 288 nodes total per tree arm, maximum 63. Mean CPU (including shared preparation): root 3.558 ms, MILP 41.181 ms, tree with MILP 134.055 ms, tree without MILP 99.238 ms. Prefer the cheap chain and face path first; only invoke integer disjunction when needed. MILP remains optional; its main value on the exposed SG-27 trajectory is incumbent recovery.
