# SG-02 source-bound spectral span, v0.1

Source: SG-01 (same PR) and OpenAI's November 24 Euclidean spectral prices. The previous unanchored penalty has zero cost for any singleton consumer even at a distant visit. Explicitly put the common producer at x_0. For consumers at ordered x_1,...,x_T with mask M, exact price for one binary label is max({x_i:M_i=1} union {x_0}) - x_0. This treats consumers as copies of a common discrete label, not arbitrary recurrent state or measured mutual information.

## Exact result
Write d_t=x_t-x_(t-1)>=0 and A_t the set of labels consumed at t. The total anchored cost for unit-bit independent labels is C=sum_t d_t * |union_(s>=t) A_s|. Proof: each label contributes every gap until its last selected consumer; interchange the finite sums. If |A_t|=k_t, each suffix union has at least max_(s>=t) k_s members. Taking A_t as the first k_t labels in one fixed order simultaneously achieves equality. Thus min C=sum_t d_t max_(s>=t) k_s. For six unit gaps and three labels per visit the minimum is 18. This is a theorem for the abstract shared-label schedule; it imposes no utility constraints and does not bound physical time or memory traffic.

For arbitrary random consumer masks, E C uses the exact suffix union probability per label. Given only marginal probabilities p_s, each suffix probability lies between max p_s and min(1,sum p_s). Independent Bernoulli masks give 1-prod(1-p_s), which is not generally valid for correlated gates. With x=(0,1,2) and p=(1/2,1/2), perfectly coupled, independent, and mutually exclusive masks cost 1, 1.25, and 1.5 respectively. Joint mask samples directly estimate the true expected hard cost. The lower bound is achieved simultaneously by a common uniform threshold. For two consumers, the exhibited exclusive masks attain the upper bound in the example.
