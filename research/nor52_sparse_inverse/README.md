# NOR-52: exact sparse-support inverse and GMP phase audit

The first [preregistration](REGISTRATION.md) was frozen at commit **9526627e21b429e7fea1928b3ddfb0e1dadc5e74**, before generating any NOR52 source or CPU timing. It follows the immutable [NOR51 negative result](../nor51_exact_r_crossover/RESULTS.md): original engineering FAIL, 2/5, with worse GMP/native verification ratios as precision increased.

The mechanism is an exact formal-series identity. Given F(x)=H(x^s) with H(0)=1, the inverse F^(-1)(x)=H^(-1)(x^s), so a sparse source of full length m can have its inverse computed on L=floor((m-1)/s)+1 coefficients. For s4 and m3073 the reduced inverse has only 769 coefficients. The complete output is restored with signed integer zero entries and the original full-size NOR45 independent Merkle root. This is full signed exact arithmetic with no field reduction.

The [algebra](algebra.py) checks the claimed stride against every original input coefficient and every original full-length untrusted inverse witness coefficient, then checks the truncated *exact* compressed GMP identity while enforcing original full signed-coefficient and packed-bit resource caps. Any forged off-support witness/source coefficient is rejected. This component is an algebra-only inverse kernel. It makes no new signed-program/session/provider claim at m3073, and is neither succinct nor zero-knowledge.

The 60-case new [public-only source fixture](cohort.py) is a fresh deterministic 2×3×5×2 grid with m769/1537/3073, dense s1 2-bit, sparse s4/s8 2-bit and sparse s4 8/16-bit, plus both seeded and alternating sign families. Every SHA identity is disjoint from NOR51's original 48 sources. CI first freezes and uploads the public-only fixture, then the **dependent** separate CPU job performs all exact inversions. No private target, reference inverse or timing appears in the first source-only record.

The [CPU benchmark](benchmark_cpu.py) runs five interleaved whole-result repetitions for four arms, rebuilding the identical full Merkle root in every arm: native full inverse, native compressed inverse, GMP original full witness verification, GMP checked compressed witness verification. The trusted reference inverse and witness JSON serialization are charged separately outside the four arms. The [microphase profiler](phase_kernel.py) independently checks NOR47's complete convolution after whole-arm timings, dividing its cost into parameter validation, GMP packing, integer multiplication, digit extraction, and signed offset correction. Microphases are diagnostics and do not change the registered comparisons.

The [source-free test suite](test_algebra.py) includes exhaustive finite small-series identity checks, explicit off-support source and witness corruption, invalid stride, wrong sign, wrong unit, overcap bounds and exact phase-parity tests using only toy inputs and prior NOR51 archive data. Existing NOR50 signed-authority and NOR51 original negative-result audits remain in predata CI.
