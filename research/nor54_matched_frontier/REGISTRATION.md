## Exact arithmetic and scope

All arms compute the **identical full-length** independent NOR45 Merkle root. NOR52 compressed native computes its own inverse; NOR53 fast GMP verifies an *externally supplied* full inverse using the original full-length source/witness unit, builtin-integer, off-support and NOR47 MAX_COEFFICIENT_BITS 32768/MAX_PACKED_BITS 120M resource checks before fast compressed multiplication. The complete full witness must pass the exact signed identity F*R=1 modulo x^m. The same fixed per-source stride is a public source property and must be validated rather than trusted as a hint.

This is an algebra-only full-output kernel benchmark on synthetic sources. Length m3073 is outside NOR45's current signed-native authorization grammar.
