# NOR-54: source-matched compressed native vs fast packed-GMP exact verifier

The first [preregistration](REGISTRATION.md) was frozen at commit **10e7ac3c3fdefec89d90d7a98a947099db8af86e**, before generating any NOR54 source or first CPU timing. The experiment follows NOR52's first exact support-compression PASS and NOR53's first native GMP pack/unpack PASS, each with immutable raw CPU and source archives. Their different CPU panels and source identities prevent a directly matched crossover claim from those separate runs.

NOR54 compares compressed-native exact inverse generation with fast packed-GMP exact verification of a *supplied untrusted witness* on **the same new sources and runner**. Four arms independently rebuild the same original full-length signed integer output and NOR45-format Merkle root: full native, compressed native, fast full GMP and fast support-checked compressed GMP. A fifth arm freshly produces the compressed native inverse, expands to full length, serializes the complete decimal-integer witness, parses it, independently verifies it through fast compressed GMP, and generates the full original root. This fifth local cost includes complete producer/codec/verification arithmetic. Real provider signatures, network and remote transport remain external.

The [source-only 60-case generator](cohort.py) uses a new NOR54/SOURCE/v1 SHA domain and the same fixed 2×3×5×2 source grammar as NOR52/53. All new public IDs are SHA-disjoint from the 168 archived first NOR51–53 source IDs, verified against their original zip SHA. An upstream CI job freezes and uploads the entire source fixture SHA **before** any dependent first CPU job restores a reference inverse or measures runtime. No private target or timing occurs in this upstream source-only step.

The [local witness producer](producer.py) checks canonical decimal JSON encode/decode and recomputes the complete inverse on each call before the [NOR53 fast GMP verifier](../nor53_native_pack/fast_kernel.py) independently validates the provided full witness. Its output and Merkle root must match the separate NOR51 full native reference. The original full-size signed integer resource cap, zero support, stride admission and unmodified NOR46 global verifier remain mandatory in all relevant arms.

The first [CPU benchmark](benchmark_cpu.py) measures five source-seeded interleaved repetitions of each whole-output+full-root arm at m769/1537/3073, covering 2/8/16-bit coefficient profiles and stride1/4/8. The independent full native reference inverse, its SHA root and witness JSON serialization are measured separately outside the timed arms. Registered primary endpoints are the **16 sparse m3073** fast-compressed-GMP/compressed-native ratio (<0.85), the **same 16** local complete producer+serialize+verify/compressed-native ratio (<1.50), and dense stride1 overhead (<1.10 in native and GMP). Full 60/60 vector/root parity, adversarial source/witness/source-SHA controls, and first-source/5-repeat immutability round out the five frozen gates.

All five original first gates must PASS for engineering PASS; otherwise the first outcome is an immutable engineering FAIL. The exact first raw CPU/source bytes and gate decision require an independent SHA receipt and permanent read-only CI before merging. Report post-hoc stratification and ten-block uncertainty as secondary diagnostics without changing preregistered thresholds.

**Domain limitation:** synthetic public formal-series algebra with transparent, nonsuccinct full output witnesses. m3073 remains outside the original NOR45 signed-program grammar. This benchmark does not establish honest external providers, authenticated cross-machine transport, zero knowledge or a cryptographic proof.
