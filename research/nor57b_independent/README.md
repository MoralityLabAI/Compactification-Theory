# NOR-57B: fresh prospective signed native/GMP selector test after first NOR57 reporting FAIL

The first original NOR57 source-first CPU job completed 60 source comparisons and then crashed in its summary reporter before producing a first CPU JSON or five-gate score. Its [original failed job log and SHA-locked public-only fixture](../nor57_authenticated_router/RESULTS.md) remain independently archived as an **unscored engineering FAIL**. A post-error source-free regression test fixed the reporter key mismatch. This new **NOR-57B** study is a separately preregistered fresh source experiment, not a relabeling or retrospective rescore of NOR57.

[Preregistration](REGISTRATION.md) commit **0a9467ae18df3296d8fdf04971f0ffbbb4c6e3d7** freezes the **same original NOR57 source-only selector and five gates** before any new NOR57B source IDs or timing. The [60-case public-only cohort](cohort.py) uses new SHA domain NOR57B/SOURCE/v1, 2 replicate blocks × m769/1537/3073 × profiles s1-b2,s4-b2,s8-b2,s4-b8,s4-b16 × seeded random/alternating signs. The source generator checks all **408 original first NOR51–57 source SHA IDs** using their original immutable archive ZIPs, including the 60 in the unscored NOR57 failure log. A separate upstream CI job fixes this first source SHA before a dependent signed CPU job can generate reference inverses, signatures or timing observations.

The three original [source-matched signed verifier arms](benchmark_cpu.py) use NOR57's identical common full signed-v2 witness acceptance code: original NOR53 exact GMP inverse, exact NOR45 reduced native inversion recomputed from independently trusted public source and matched against every received signed integer witness coefficient, and the **frozen public source selector**. The selector routes **NATIVE iff** original trusted public input stride4, length m769 or 1537, maximum *actual* source coefficient bit length exactly16, otherwise GMP. The registered grid implies exactly **8 native** and **52 GMP** branches.

Every timed arm consumes the **same prebuilt Ed25519-signed compact-v2 bytes** with independent source SHA, public source-vector digest, pinned fixture key, original full root premise, full resource cap, nonce/session and replay guard. Five source-seeded interleaved full-witness/full-Merkle-root CPU repetitions per source and arm occur on one pinned Ubuntu24.04 Python3.12 gmpy2 2.3.2 cryptography46.0.4 runner. Reference witness production and signer costs are logged separately outside the whole-verifier timings. All 60 full exact integer vectors and independent Merkle roots must match.

The **five unchanged gates** demand (1) all-60 ratio of sum of selector source medians / sum of GMP source medians strictly <0.95, (2) eight native-selected median native/GMP sourcewise <0.85, (3) 52 GMP-selected median selector/GMP <1.10, (4) identical full exact vectors, original roots and hostile signed attack controls on all sources, (5) upstream source SHA, 408 prior exclusions, fixed 8/52 routing, five repeats, original resource caps, reentrancy and immutable complete first NOR57B CPU/source evidence with read-only SHA audit. Any first NOR57B FAIL is permanently preserved; the earlier NOR57 first FAIL remains unscored and unchanged.

The signed Ed25519 private fixture key is intentionally **public and test-only**, the witness is transparent and nonsuccinct, m3073 lies outside NOR45 signed native-program authorization, and real cross-host transport/provider honesty are external. Exact arithmetic correctness and future Lean kernel proofs remain separate questions.
