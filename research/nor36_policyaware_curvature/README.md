# NOR-36: policy-aware greedy attack against within-atom curvature auditing

**Prospective registration:** [REGISTRATION.md](REGISTRATION.md), first NOR36 commit ede05db on 2026-11-17, before new source/attack/audit data. Continuation of [NOR35](https://github.com/MoralityLabAI/Compactification-Theory/pull/208), which showed a +16.73 percentage point exact conditional detection gain on high-curvature attacks from within-atom feature targeting at fixed source/trial eight-atom quotas.

NOR36 gives six public auditor distributions **equal-budget approximate policy-aware attackers**. Original hybrid50, quota-redrawn random hybrid50, curvature50 hybrid50, pure uniform16, the original six-arm NOR31 mixture and its curvature50 transformed version all use 16 exact target-output coefficient witness queries. Each defender-specific attacker receives eight independent tie-restart greedy searches over the ENTIRE m=769/1537 output positions, using the SAME 256 source-specific CAL schedules per defender. Attacks commit four changes before 512 independently salted held-out challenge schedules. The new source-only fixture includes 24 fresh RRC25 inputs (reps 52–55, D512/D1024, three original NOR21 families), SHA-disjoint from 132 archived historical public sources.

The registered primary contrasts test whether the curvature-transformed auditor loses against its own optimized attackers, whether it loses against the original auditor on the EXACT same attacks calibrated against curvature, whether its high-curvature blind support gain continues on the fresh source cohort, and whether the frozen NOR31 mixture also suffers policy-aware erosion. All empirical comparisons are source-paired across **24 independent sources**; repeated 8 attack restarts and 512 audit challenges are correlated. A primary gate fails if a registered source-win or source-mean threshold misses, and the original FAIL is preserved with immutable raw first-run source/grade receipts.

Exact NOR35 top-curvature hypergeometric conditional expectations are reported separately from 8 finite blind attack sets per source. Additional bottom-curvature, eight atom-quota matched and whole-output uniform controls and complete six-by-six calibrated cross-play are recorded, including realized categorical mixture diagnostics. The source generator reconstructs private original RRC25 targets only after all public decisions, attack sets and audit plans have been frozen. An external authenticated target coefficient witness and independent hidden audit coins are assumptions. Public SHA-seeded deterministic trial streams are not cryptographic secrecy; a fully schedule-informed attacker may always evade a partial audit.

Mathematical companion [MathCan NOR36 #130](https://github.com/patrickdugan/MathCan/pull/130) proves explicit finite public-prefix avoidance despite equal per-atom query budget and exact independently sampled uniform-reserve no-hit counts for precommitted calibration-aware attacks. The registered greedy attack is approximate rather than formally global minimax.
