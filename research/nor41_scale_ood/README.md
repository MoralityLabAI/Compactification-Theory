# NOR-41: nested attacker CAL budgets and block-structured input OOD

[NOR-41 PR #228](https://github.com/MoralityLabAI/Compactification-Theory/pull/228) implements the prospective [registered protocol](REGISTRATION.md), first commit `87dd3de03f43e79d83d45ed7a5c3a3bb1f20746f`, with the explicitly frozen [pre-data duplicate-support amendment](AMENDMENT_01.md), first commit `e5a95cad1ffdcd019f153cd09dd4d48b40848ef9`.

The new cohort is **16 original replicate blocks × two observed degrees D512/D1024 × two input families**, for **64 novel full-public source identities** disjoint from 324 SHA-archived originals through NOR40. One family is the original `wide_dense_small` input law. The registered `wide_regime_blocks` generator imposes four 64-coefficient regimes (90% active, 4% active, 16% active only within 4 of each 16-index period, and 25% active). It uses the unchanged original RRC25 program/suffix grammar. The new family tests source-input **distribution shift** while preserving the program-family class.

The four trained auditors remain `uniform16`, `original_mix`, `deterministic_mix` and `global7_mix`, with a fifth fixed `atom_random_h50` feature-only diagnostic. Each auditor queries 16 authentic target-output coefficient positions. Attackers alter four distinct coordinates fixed before the EVAL challenge schedule. Every auditor receives symmetric source-public CAL budgets of **256, 512, 2048 and 4096** schedules, nested as prefixes of the same 4096-schedule stream. Every policy/budget uses 16 seeded greedy starts, two deterministic CAL-only swap refinements, exact enumeration of 1,820 four-sets over a frozen 16-coordinate pool, and an original-CAL-dominance-constrained eight-support selection. The selected attacks are frozen before **1024 independent EVAL** schedules. Four policy attackers × four budgets plus six blind controls yield complete 22×4 heldout crossplay.

The five original scientific gates test the **degree-dependent difference in attacker transfer**, OOD exact TOP-curvature benefit, CAL4096-to-EVAL transfer, strong Global7 worst-class coverage relative to original/deterministic mixtures, and exact source-first/replayer/native-witness integrity. Every Boolean remains PASS or FAIL as scored. The first-run score will be reported with source-level means, 16-replicate-block intervals and separate input family/degree effects. An exact optimum within the 16-coordinate pool is a pool-restricted certificate; the fourth-smallest full-domain singleton exposure provides a sound but generally loose global CAL lower bound.

Pre-data tests use SHA-archived NOR40 original sources and synthetic input/mask fixtures. The [independent replayer](receipt_audit.py) reconstructs the new input grammar separately, all 64 native programs, the source-curvature audit plans, 4096-CAL nested attacks and every heldout crossplay decision. The source-first GitHub Actions workflow SHA-freezes and uploads all **64 public-only source records in a separate job**, before allowing any new-cohort CAL/EVAL plan generation or true native target reconstruction.

The earlier NOR38 source-preview issue is explicitly covered by [predata_isolation_audit.py](predata_isolation_audit.py). The graded result is conditional on an external authentic target-output witness and hidden independent audit coins. Public SHA pseudorandom streams are reproducible research fixtures, not deployed secrecy.
