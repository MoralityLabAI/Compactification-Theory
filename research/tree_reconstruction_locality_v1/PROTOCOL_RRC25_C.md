# KSR-01C: frozen recurrent-state audit before threshold transfer

Registered 2026-11-14 before running this adapter. This extends KSR-01 with a test of the original broadcast assumptions on the existing RRC-25 GRU. No new network training, GPU work or LoopedTransformers checkpoint substitution is authorized by this protocol.

## Frozen source and observable

Use research/rrc_compactification/bench25.checkpoints(), which validates all original checkpoint training-source hashes, model shapes and step counts. Select its recurrent 1,000-parameter GRU and retain its original JSON SHA-256. Replay its nine public 8-dimensional feature rows from zero hidden state, using its native portable affine/sigmoid functions, and require final logits to equal model25.logits within 1e-12. A root's observable label is the first-template U index of its highest-ranked 16-way candidate: argmax(logits)//4, with lowest index resolving ties. This is an output-ranking label, not a ground-truth proof state or hidden reasoning label.

Generate 12 calibration cases per original training family (signed, sparse, product) using seeds 940229237+1009*family_index. Generate 24 held-out cases per original six test families using seeds 940229238+1013*family_index. Each case is generated by compound25.make_case. Public-header selection uses only possible_headers(case)[0]. Require disjoint visible inputs and IDs; case.future and program may not be consulted by feature extraction or inference. Report all labels, their empirical prior, and missing label classes.

## Finite branching intervention

Collect the public feature rows from calibration cases. With Random(940229239), select eight row positions without replacement to form a frozen input bank. The bank and its SHA-256 are shared across every root and every level. Each edge independently picks one bank index uniformly, then applies one original GRU step to the parent's full hidden vector. Rows may coincide in value; the uniform law is over bank positions. This is an artificial continuation beyond the original nine-row input, with no assertion that it lies on the native training distribution.

Use b=2 and depths L=1,2. Enumerate each node's eight possible next hidden states exactly (portable float64 arithmetic), then retain exact rational probabilities over the resulting discrete labels. Root probabilities are uniform over the declared finite case cohort, giving a generally nonuniform four-label prior. No model parameter changes occur.

## Assumption checks

For each occupied parent label a, compute p_h(j)=Pr(child label=j | full parent state h) from the eight bank rows. Report T_a=E[p_H|C=a], J_a=E[p_H p_H^T|C=a], and Delta_a=sum_j Var(p_H(j)|C=a). Delta_a>0 is an exact finite-law witness of sibling dependence after conditioning only on the parent label. Store two same-label roots with the largest child-law total-variation distance.

Fit the symmetric four-state channel's least-squares coefficient lambda=(trace(T)-1)/3 on calibration roots only, provided all four label rows occur. Measure held-out row total variation from that frozen symmetric channel. Separately enumerate the true two-step single-path channel and compare it to the square of the one-step channel. Missing classes make that stationary composition gate unavailable, rather than being filled with guessed rows.

The original KSR symmetric-tree formulas are eligible only under their exact assumptions. Empirical coefficients and b*lambda^2 here are descriptive diagnostics; they establish no neural phase transition or universal reconstruction bound.

## Dependence-robust finite score

For each fixed full hidden root, compute the distribution of depth-L leaf histograms by bottom-up exact Fraction convolution, integrating over the eight input choices at each edge. Enumerate a finite joint law of root label and leaf counts. Compute the exact MAP accuracy for that finite empirical source prior. Also compute the new arbitrary-prior covariance lower bound, which has no tree or sibling-independence assumption at the coarse-label level. Its decoder is fitted to that same finite population, so it is a population diagnostic with no held-out decoder-generalization claim.

Report calibration and held-out root cohorts separately, counts of native GRU transitions, tree leaf symbols, integer count bits, and the stored posterior table size. Exactness means discrete probabilities conditional on the frozen floating-point model replay, not a proof about real-arithmetic GRU dynamics.

## Required checks and outputs

Test native logit replay, future-label mutation isolation, frozen input-bank hashes, no negative probability, distribution normalization, count MAP no lower than the robust covariance bound or prior-majority guess, counterexamples for coarse sibling independence, and every output's source provenance. Save a machine-readable report and all dependency witnesses in CI artifacts. Keep the source checkpoint and existing KSR-01/01B outcomes unchanged. No merge is requested.
