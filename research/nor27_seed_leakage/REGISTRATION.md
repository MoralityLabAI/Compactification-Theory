## Distinct leakage games and hypotheses

**Game A: released reserve-coordinate prefix.** Public trained-risk targeted prefix T has size t=8. The auditor draws u=8 uniformly random reserve coordinates without replacement from the m-t other positions. Before committing an alteration A of r=4 positions, the attacker observes the first ell of the *actual ordered reserve*, for ell in **(0,2,4,6,8)**, as well as public T. The attacker must select only positions outside T and those ell leaked indices, and receives no information about the unrevealed u-ell positions. The remaining draws are conditionally uniform. At ell=8, the complete 16 checked positions are known, so an informed attacker evades with certainty.

The conditional minimax detection probability is exactly

    q(m,t,u,r,ell) = 1 - C(m-t-ell-r,u-ell)/C(m-t-ell,u-ell),

provided 0<=ell<=u and m-t-ell>=r. This describes revealed random *outputs*, rather than guessing a number of raw seed bits.

**Game B: leaked high bits of a 64-bit sample seed.** A separate attacker sees only the upper **b in (0,2,4)** bits of a 64-bit uniformly sampled secret seed S, along with public source and policy, before choosing four altered coordinates. Auditor schedules are deterministically generated by hashing S with public source and a domain-separated policy label, then using Python Random to sample the reserved coordinates without replacement. Knowing b high bits alone leaves 64-b unknown bits *under the ideal uniformly sampled seed model*. The attacker fits an approximate greedy attack separately to each known b-bit bucket using independently seeded calibration schedules, never evaluation schedules. This experiment probes the empirical seed-to-schedule mixing behavior of the specified pseudorandom sampler; it is **not a cryptographic proof of entropy extraction**, and public fixed reproducibility seeds are not a substitute for deployment secrecy.

The two games remain separate in the result tables. Revealed coordinates are a direct information leak about the realized schedule; a raw seed prefix can behave differently depending on the seed expansion algorithm.

## Prospective primary scoring

The independent unit is the public source (12 units); 1024 challenge ordinals, buckets, attacks, and seed replicas within a source are repeated observations.

1. **Game A** must show source-mean detection at ell=0 at least **+0.008** above ell=4, with source-mean ell=4 strictly above ell=8, and exactly **0 detections at ell=8** in every source. This measures the predicted degradation under disclosed actual reserve coordinates.
2. **Game A** must reproduce the exact rational conditional floor for every m and ell. Every measured degree-group (six sources per output length) detection rate at each ell must be within **0.015 absolute** of that degree group's theoretical floor. This finite stochastic agreement gate does not assert a hard lower bound for empirical frequencies.
3. **Game B** source-mean seed-high-bit-leak detection for b=2 and b=4 must each remain within **0.015 absolute** of b=0 for BOTH `hybrid_50` and `uniform16`. This is a specified empirical sensitivity result for the SHA256-expanded sampler, not a proof for other RNGs.
4. Exact nonzero-shift invariance, valid-original target acceptance, independent source parity and the fully-informed complete-audit escape at ell=8 must all hold.

**PASS iff all four groups pass.** Report FAIL with unchanged thresholds if any group fails. Secondary analyses: seed-conditioned per-bucket rates, attack uniqueness, 12-source paired differences, degree-group paired changes, true seed revealed attack = 0% detection, and runtime. Source-level bootstrap is descriptive only.
