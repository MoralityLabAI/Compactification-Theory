# SMC-14: Calibration-frozen cross-checkpoint causal transfer

**Registered November 16, 2026, before the heldout intervention run.** Companion mathematics: [OLM-14](https://github.com/patrickdugan/MathCan/blob/research/olm14-cross-model-causal-20261116/research/orbit_lock/OLM14_CROSS_CHECKPOINT_CAUSAL.md). Continues the merged SMC-13 observational feature-alignment campaign.

## Scientific question

After controlling for visible Sudoku clue and position, SMC-13 found nontrivial activation coincidence between independently trained recurrent models. The new question is whether its **exact calibration-only feature permutations** predict which decoder interventions change a task-relevant digit margin in corresponding ways across the teachers.

Two newly trained recurrent teachers have missing-cell accuracy around 45–47%, versus about 96% for the externally pretrained teacher A on novel-30 Sudoku. This mismatch is a primary interpretation limit. The hypothesis concerns **signed causal responses**, not equal teacher capabilities or exact semantic feature identities.

## Intervention and task contrast

For each puzzle, choose exactly **eight** missing positions spread evenly across the ascending 30 or 34 visible blanks, using their indices 0, floor(n/8), ..., floor(7n/8). Positions depend solely on the publicly visible input zeros.

At every chosen position, take the highest positive source SAE feature t from the source teacher's FP32 post-stage-one token activation. Its frozen calibration assignment gives matched target feature π(t). Apply a finite intervention in the original physical hidden state, along the source decoder d_t and the corresponding target decoder d_{π(t)}, independently normalized to unit L2 length after the source FP32 decoder×scale product. The same ±0.2 perturbation radius is used for both models. The other 80 token states are held fixed in each intervention episode, while the full recurrent block propagates the perturbation through three more iterations in FP64.

The task utility is the **ground-truth Sudoku digit margin** at the chosen missing cell: correct digit logit minus the *clean highest competing digit* for that teacher and puzzle. The competitor is chosen using only the clean prediction and frozen before either intervention. Targets enter *only* the causal response scoring and the global sign calibration on the 64 calibration puzzles; they never choose the teacher checkpoint, SAE weights or feature mapping. Measure the central causal response

\[
d_{p,g}(T,t)=\frac{m_T(h+0.2\,u_t)-m_T(h-0.2\,u_t)}{0.4}.
\]

Separately report clean missing-digit correctness of each teacher on the selected goal positions and the target SAE's matched-atom top-four activation rate. All teacher logits and finite interventions are evaluated on the original source stage-one FP32 binary anchors with FP64 continuation. These are **numerical causal interventions**, not Arb interval-validated effect certificates.

## Primary causal transfer score and orientation

For each 8-token puzzle, subtract the mean response across its eight chosen positions from each teacher's response vector. Compute the centered cosine of the two response vectors and retain a missing/abstention status if either vector has zero norm or some source SAE highest neuron is not strictly positive.

One **global ±1 orientation sign** per teacher/SAE pair and feature assignment is chosen from the separate 64-puzzle calibration cohort by the sign of the sum of centered source-target causal response dot products. This orientation is frozen before any test puzzle response is inspected. Each control mapping fits its own sign from the same calibration cohort, so a matched-assignment benefit cannot be attributed to giving the treatment arm an extra sign parameter.

The main result is the mean oriented within-puzzle centered cosine on novel-30 test puzzles, reported for each of four A→B pairs. Replicate on novel-34 as a second preregistered distribution. Canonical 30-hole is a transfer-regression control.

## Negative controls and acceptance gate

For every pair, preserve the same source model, test puzzles, target model and SAE snapshots, goal positions, correct digit labels and intervention norm. Only the frozen correspondence changes.

- The **within-clue-group shuffled calibration assignment** from SMC-13C is the main hard null. It uses the same 64 calibration inputs, centers by position+visible digit and independently shuffles target activity inside each group before Hungarian matching.
- A deterministic uniformly random one-to-one feature permutation is an additional negative control; its global orientation is likewise learned from calibration-only causal responses.
- An evaluation-only within-puzzle random shuffle of target response positions preserves each puzzle's causal-effect histogram and removes correspondence of positions. It is a descriptive third null, independent of feature assignment.

For each of 64 independent puzzle clusters, retain the treatment-minus-null paired cosine difference. Use 2,000 fixed-seed puzzle-level bootstrap resamples to report descriptive 95% intervals, with all three cohorts kept distinct. Do **not** treat 8 tokens, 96 features or two SAE fits on the same teacher as independent puzzles.

**Strict registered positive gate per pair:** On *both* novel-30 and novel-34 cohorts, the matched mean cosine must exceed the within-clue-shuffled feature assignment and the random permutation assignment, with the paired 95% puzzle-bootstrap lower bounds for both differences above zero. Report any zero-variance or source-tie abstentions. Across four source→new pairs, retain each result and apply no posthoc favorite-seed selection.

A positive result establishes a calibration-frozen predictive association between matched SAE interventions and task-digit margin responses **under the specified controls**. It does not prove a shared causal circuit, equal model capability, or transfer of Sudoku-solving skill. A null result is an equally informative outcome.

## Reproduction

The experiment depends on the GitHub Actions artifacts of SMC-11C and SMC-13A/13C. Each source JSON hash, teacher checkpoint tensor fingerprint and SAE snapshot hash is checked before evaluation. The code re-creates the three puzzle cohorts and validates the exact roster manifest.

Run from the repository root with Python 3.11 and pinned CPU PyTorch 2.7.1:

    python -m unittest discover -s research/real_recurrence_sae_v1 -p 'test_smc14_causal_transfer.py' -v
    python research/real_recurrence_sae_v1/smc14_causal_transfer.py --fetch-source --original-artifact PATH_A --independent-artifact PATH_B --conditioned-receipt PATH_C --out runs/smc14/full.json

The dedicated CI has a smoke test and a complete source-locked 7-pair × 3-family × 64-puzzle evaluation, uploading per-puzzle evidence and a calibration-only orientation receipt. Theoretical transfer conditions in OLM-14 are not claimed as verified on these source models: the experiment measures finite causal responses in FP64.
