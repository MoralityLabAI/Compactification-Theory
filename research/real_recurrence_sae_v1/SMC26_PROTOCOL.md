## Frozen sign policy and utility

Each scalar predicted effect p maps to an action a in {+1,-1,0} by a=+1 if p>+0.15, a=-1 if p< -0.15, else 0. The registered true effect class t is +1 if D>+.15, -1 if D<-.15, else 0. A predicted action chooses whichever of kill/sham gives better true-digit margin; a=0 means abstention.

The per-goal utility U(a,t) is +1 for correctly classified nonzero t and matching nonzero a, -1 for opposite signs, and 0 when abstaining on a nonzero t. For a true neutral t=0, U is +1 for abstention and -1 for either nonzero action. Subtract 0.10 utility units from any nonzero action to represent action overhead. Every input-ineligible goal receives U=0 for all policies. This is a fixed *offline causal decision utility*, not a claim about deployed trading, control or improved Sudoku solving.
