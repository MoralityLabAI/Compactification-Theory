# SMC-24E: Pre-outcome numerical-replay repair

**Engineering amendment, 17 November 2026, after pretest calibration and source-only predictions but before any native test effect was scored.** Original scientific registration in [SMC24_PROTOCOL.md](SMC24_PROTOCOL.md) is unchanged, including cohorts, ridge parameters, controls, sample unit, physical edit cap, and all 8 adjusted test gates.

The initial hosted run [#44103770025](https://github.com/MoralityLabAI/Compactification-Theory/actions/runs/44103770025) completed its 64-old-puzzle calibration and archived fresh **input-only** predictions. Its scoring job halted on the first case at the cross-runner input-plan equality assertion, before reading/recording task effects. The source code demanded Python dict equality of float diagnostics from two separately evaluated CPU linear algebra/SVD paths. Such equality is stronger than the protocol's physical-dose and source-recoding numerical constraints, and can fail when the final low bits of LAPACK or a trained forward change across hosts. The original input-only prediction artifact is retained as an engineering receipt, with zero scored native outcomes.

**Frozen canonical handoff:** the prediction-only stage must now save all 81x48 FP32 post-stage-one tensors for each of the two frozen teachers and both fresh public puzzle families. These input-derived states are computed only from visible Sudoku clues and trained weights; no target labels or correct-digit margin outputs enter the prediction API. They are stored together with the frozen target-native SAE feature ID, 48D kill and hard-sham vectors, all four predicted D values, source checksums and user-independent puzzle input IDs. This archive is the one canonical physical source state for scoring.

**Pre-outcome numerical admission in scoring:** independently re-run source FP32 stage-one and require maximum absolute per-element discrepancy against the archived stage-one tensor <= 1e-4 for every teacher/puzzle, recording each discrepancy. If this check fails, abort the entire scientific job and retain the engineering failure. Evaluate all native clean, zero-self, kill, sham and mirror arms from the **archived FP32 physical state**, with the frozen source teacher's FP64 three-block continuation. Check clean/zero self bit equality and all-logit source parity within the scoring host. Validate each archived input edit and SAE support afresh using the frozen encoder: target highest-positive rank, top-four support, target erasure, other-three preservation, sham all-four preservation, exact input physical norm equality within 1e-8 and the original dose cap. The original task-blind 33-candidate sham choice is evaluated during prediction only; using its archived winner in scoring prevents any posthoc re-selection. If an edit violates these checks on the archived state, abort; never substitute an alternative or alter eligibility based on output.

**Chronology:** re-run all four CI stages from scratch, generating a new calibration artifact, new input-only frozen prediction artifact with archived full stage-one tensors, then native scored outcomes and independent receipt audit. The original pretest artifact is not reused. This amendment is strictly an engineering data-path repair, and the original registered acceptance thresholds remain fixed. Old held-out outcomes from SMC-14 through SMC-23 and the sealed ARG-03-N cases remain untouched.
