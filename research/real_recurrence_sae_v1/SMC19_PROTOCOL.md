**Prospective preregistration, November 16, 2026.** This protocol is the first SMC-19 commit, predating all SMC-19 new-SAE training, calibration and fresh-cohort evaluation. Stacked on [SMC-18 PR #182](https://github.com/MoralityLabAI/Compactification-Theory/pull/182); SMC-18's source-locked 3/4 gate, receipt hashes and original trained weights remain unchanged. New work is in \`research/smc19-sae-refit-gauge-20261116\`. Mathematical companion OLM-19 will state exact coordinate-conjugacy and non-identifiability theorems.

## Research question

SMC-14 through SMC-18 measured matched SAE decoder effects across recurrent Sudoku teachers, culminating in a task-gradient explanation of the observed physical edit with a full-rank inactive-feature gauge obstruction. Is the feature-to-effect correspondence robust to a genuinely **independent SAE refit on the identical frozen teacher**, and which parts of the evidence survive exact hidden-coordinate reparameterization?

Two distinct sources of change must remain disaggregated: (A) purely invertible/orthogonal coordinate rewrites with model and SAE transported together, and (B) a stochastic refit whose learned dictionary may differ. Exact A invariance is a *required software and gauge sanity check*, not evidence for B.

## Calibration-lock phase (must finish before fresh heldout input construction)

After new SAE refit files have been saved and checked, obtain stage-one states for exactly **64 original SMC-13 \`feature_calibration\` puzzles**, with the original teacher weights. For each teacher × new SAE fit, take the original SAE71 and new SAE131/167 **binary top-four activity** at all 81 token positions. Compute a 96×96 maximum-weight Hungarian assignment from group-centered coactivation covariances conditioned on the publicly visible \`(position, input digit including 0 for blank)\`, using the exact SMC-13C \`conditional_affinity\` implementation. Frozen hard null: within-condition-group target code shuffling before identical Hungarian matching, with deterministic shuffle seed \`202619710 + pair_index\`. Frozen random assignment: \`random.Random(202619810 + pair_index)\` permutation of 0..95.

Record SHA-256 hashes for all three permutations and the complete calibration support/assignment hashes before loading any SMC-19 test cohort. Record exact source teacher/SAE fingerprints, training/validation roster manifests, refit weights and calibration states in a **separate** immutable training-and-calibration artifact. This artifact is the only input permitted to test-scoring jobs in addition to immutable prior checkpoints. Under the original matching, code-overlap controls on calibration are observational; no Sudoku gold digit selects a map.

Calibration-only **global orientation signs** for the two causal arms are computed from the original 64 calibration puzzles **after mappings are frozen**. The sign for an arm is \`sign(sum(E_reference·E_target))\` on strictly source-top-one and receiving matched-atom-active goal tokens (the same eligibility mask for both arms). E is clean-correct-digit-minus-clean-rival margin drop after native physical SAE decoder-contribution removal at one original FP32 stage-one goal token, followed by three FP64 recurrent steps. The alternative arm is an equal-physical-dose edit along a **different naturally active receiving SAE decoder column**, deterministically selected from frozen code using the original SMC-15 source-independent active-alternative selector. Each arm receives its own calibration sign. An all-zero/empty calibration sign is \`unidentified\` and invalidates the corresponding pair; it is never fitted on tests. Calibration labels may enter these orientation signs but not model fitting, Hungarian mapping, alternative-atom selection or any heldout model choice.

## Primary within-teacher independent-refit causal stability

Four pairs, frozen order: B501 original SAE71→B501 refit SAE131, →SAE167; B701 original SAE71→B701 refit SAE131, →SAE167. For a selected goal choose **strict positive unique top-one reference SAE feature** i and frozen matched new SAE feature π(i). Eligible only when π(i) is naturally active with positive top-four coefficient in the new SAE and at least one *different* new SAE feature is active. For each eligible goal, the original SAE source feature and refit matched new target feature each have their native physical decoder contribution removed independently, from the SAME unchanged teacher's stage-one hidden state; all other 80 token states stay unchanged at injection. The target other-active control subtracts the same physical L2 dose as the matched target along another naturally active target decoder direction. Preserve clean FP64 3-step rollout and frozen correct-digit competitor, goal accuracy, physical norms, all SAE coefficients, post-erasure re-encoded activation, clean-correct→wrong flips and raw per-goal margin drops. Ineligible tokens keep exact reasons; they are never given zero effect in the denominator.

For each eligible goal, let \`sig(E)\` be 0 for \`|E|≤1e−8\`, else ±1. Compute signed matched correspondence \`sig(E_reference) sig(E_matched_refit) s_matched\`; the same source erasure gives \`sig(E_reference) sig(E_other_active) s_other\`. The primary paired goal difference is **matched minus other-active signed correspondence** on the identical eligibility mask. Report pooled token-weighted mean and per-puzzle average, plus 2,000 fixed-seed bootstrap resamples of **64 puzzle IDs** (all eight goals kept together) for a descriptive 95% interval and abstentions.

**Preregistered positive gate per pair on BOTH novel cohorts:** (1) at least **24 eligible goals across 20 independent puzzles**; (2) both calibration-only orientations identified and all 2,000 puzzle-bootstrap draws valid; (3) paired matched-minus-other-active mean **95% bootstrap lower bound strictly greater than 0**. Report all four comparisons even when any fails; no best-seed selection or retrospective threshold change. This is a test of *refit stability for native SAE contribution interventions in a frozen teacher*, not shared reasoning circuitry or a statistically independent population replication. Report the original same-teacher SAE71→SAE89 historical data only as labeled context.

Secondary, non-gating: heldout activation overlap of matched vs source-clue-shuffled/random mappings, target matched-atom activity/coverage, class flip rates, physical decoder cosine, observed mean task-margin changes, permutation SHA-256 and original trained SAE cone counts. Shuffled assignments have different natural-activity masks; never promote raw differences in their coverage to the paired primary gate.

## Required exact hidden-coordinate transport control

Using the original source-locked B501 teacher and its original SAE71, generate a **single deterministic 48×48 orthogonal Q** by QR from seeded standard-normal CPU tensor generator seed **20261919**, with diagonal sign convention. Convert original physical stage-one hidden state h to hQ, original physical decoder delta d to dQ, and evaluate the *same unmodified frozen recurrent teacher* after transporting the edited states back with Qᵀ. The transported SAE computes \`encode(((hQ)Qᵀ−μ)/scale)\`, and decoder reconstruction rotates by Q. Evaluate original and transported codes, clean Sudoku logits and native-erasure task-margin response on the **same fixed four-puzzle prefix of new novel30**, with all computations FP64 after original FP32 anchor. The same model weights and same SAE fitted dictionary are used with coordinate wrapper; this is **algebraic reparameterization** rather than another independently trained network.

**Engineering gate** (separate from refit scientific gate): \`||QᵀQ−I||_max<2e−12\`, maximum feature code absolute error, original vs transported clean logit error and native erasure margin-effect difference each **<2e−9**. Failure aborts the full artifact as an implementation inconsistency. It is neither counted as independent causal evidence nor used to choose a better SAE fit.

## Independent audit and interpretation

A standard-library-only independent auditor must verify the original source receipt hashes and seven Hungarian mapping locks, new refit file hashes/manifests and four new calibration mapping SHA-256, original calibration signs using raw calibration causal responses, fresh Sudoku uniqueness/manifest and exact goal positions, per-goal physical-dose equality, eligibility, raw causal sign computations, 2,000 fixed-seed puzzle bootstraps, and each gate. It checks saved numerical receipts independently; actual trained network forward passes are supplied by the source-locked PyTorch experiment and remain the trusted component. Include **full new SAE checkpoints**, training/validation/calibration metadata and full per-goal outcomes in permanent 90-day GitHub Actions archives. Source code and scripts must be public at a pinned branch SHA before claiming any scientific result.

Under exact joint orthogonal gauge transport, physical causal behavior must be invariant. Under independently trained sparse dictionaries, feature names, bases and intervention directions can differ despite similar reconstruction error. A positive four-pair result gives conditional evidence of *calibration-frozen task-functional correspondence across SAE refits* under matched controls. A low-coverage or null result limits the portability of feature causal claims; it does not retroactively change SMC-14 through SMC-18 results.
