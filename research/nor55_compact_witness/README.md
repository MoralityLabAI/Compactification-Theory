# NOR-55: exact compact signed source-bound witness and verification economics

The prospective first [registration](REGISTRATION.md) was frozen at **9f7fb42a2e0a8648db63301bed381cb7f3aa0dc2** before any new NOR55 source generation or first CPU timing. This experiment continues NOR54's immutable 60-source 4/5 FAIL, in which a supplied exact inverse could be checked efficiently by fast compressed GMP, while producing, serializing and verifying it locally failed the registered complete-computation gate.

The [public-only first cohort](cohort.py) is a fresh 60-source 2×3×5×2 factorial panel, using new NOR55/SOURCE/v1 identities excluded from all 228 first NOR51–54 source identities read from their original SHA-locked archives. The upstream source-only CI job must generate and upload the original source SHA and fixture without any inverse, witness, session, signature or timing information. The dependent CPU job uses those exact frozen source bytes.

The [compact exact payload](codec.py) carries only reduced coefficients at the independently checked support stride. Each coefficient has a canonical sign, canonical unsigned-varint magnitude length and a minimal big-endian unsigned magnitude. The codec rejects negative zero, oversized/noncanonical integers, truncated data and trailing bytes. The full original signed output vector is restored with exact zeros and the original full coefficient and GMP packed-size caps enforced. The independent original NOR45 Merkle root remains mandatory.

The [signed envelope](envelope.py) has a canonical length-delimited JSON header and raw compact or decimal JSON witness payload. A pinned Ed25519 **research-test** public key authenticates the exact message bytes, binding the protocol, source SHA, source-vector digest, full length, trusted stride, expected full result root, provider fixture ID, session, sequence, verifier-issued 256-bit nonce, payload SHA and payload byte count. A verifier's independent trusted context supplies these facts; the signed header cannot redefine them. A source/session replay guard rejects repeated nonce or sequence, marking a request consumed only after complete exact signed identity and original full-root checking. The deterministic fixture signing seed is public in repository source, intentionally unsuitable for deployment.

The [benchmark](benchmark_cpu.py) compares four exact complete-output/full-root arms across five interleaved repeats for each of 60 sources: compressed native inverse, fast GMP of supplied untrusted full witness, signed compact binary verifier, and signed full-decimal JSON verifier. Independent full native witness generation, source-bound request challenge issuance and fixture-side payload encode/signing are measured separately from verifier-only arm CPU time. First registered engineering gates require authenticated compact / compressed-native <0.85 on all 16 sparse m3073 cases, authenticated compact / authenticated JSON <0.85 on the same cases, median full signed compact envelope bytes / original decimal JSON payload bytes <0.55 across 48 sparse sources, 60/60 exact original-root parity and malicious signed protocol tests, and immutable source-first SHA, five repetitions, original caps and complete first evidence.

The optional [local TCP secondary](loopback_secondary.py) runs after the first primary CPU job. A producer process freshly computes a complete compressed inverse, encodes and signs the compact payload, and sends a length-framed signed request over actual localhost TCP to an independent prestarted verifier process, which holds the trusted full source/root and nonce contexts. Three complete request/reply samples are measured on 16 sparse m3073 inputs; process startup and nonce issuance occur outside timing. Every reply includes the verified full Merkle root and exact full-vector digest. These results are **local single-host loopback**, remain a separately preserved secondary artifact and do not change the original five engineering gates.

The [source-free tests](test_codec_envelope.py) exhaust small formal-series inverses and reject wrong source, unit, support, root, signing key/provider, signed header, replay, noncanonical integers, incorrect lengths and malformed signed wires. [Local toy TCP tests](test_loopback.py) exercise separate producer/verifier processes without generating first test sources. Previous NOR50 signed program, NOR53 exact GMP and NOR54 original immutable audit checks remain in the source-free workflow.

Domain limitations: all exact source and witness vectors are synthetic public formal series; m3073 remains outside the original NOR45 signed-native program grammar. Neither signature fixture validity, independent inverse identity nor local TCP latency demonstrates honest external providers, production signing-key security, off-host network performance, zero knowledge or succinct proof size.

**Original first CPU trigger:** source-free exact codec, pinned research Ed25519 signature, full-root, replay/session tampering, separate-process TCP smoke and original NOR54 SHA tests passed. This commit freezes the first public-only 60-source identities upstream of both exact witness size calculation and CPU timing. The original five gate decisions, PASS or FAIL, will be archived without threshold retuning. The 16-source TCP loopback remains a separate post-primary secondary job.
