**Frozen before new trained-model capture.** Earlier SCM-01 through SCM-13 registrations and RMP's G0, sealed splits, and verified checkpoints are unchanged. This registration is distinct from any retrospective analysis of SCM-13 synthetic results.

## Main question and acceptance

On original RMP `LOOP-T s1` and `FF-U s3`, can a source-verified disk Hessian bound supply a sufficiently small nonlinear remainder to preserve the affine intervention braid in a fixed readout chart? Source-only success requires a validated full-disk `H_i`, independently verified exact-real `z_i(0)` and `D z_i(0)`, and SCM-13's strict pair-clearance inequalities. A continuous neural observation additionally requires physical float32/CUDA execution error bounds and a collision-free discretized trajectory certificate from SCM-05.

For each source certificate, record checkpoint hash, source checkout revision, selected dictionary hash, exact feature IDs, input token sequence hash, chart and axis hashes, positional-frequency provenance, numeric semantics and derivative/interval source. Always preserve declined or inconclusive cases.

## Metrics and falsifiers

- Per-visit `H_i`, source-derived remainder `eta_i=||C|| H_i/2`, independently certified affine pair clearance, and full-braid null or preservation gate.
- Jacobian rank and singular values of each relative `B_i-B_j`, with interval uncertainty and exact-real provenance; refuse rank claims without a certified separation from zero.
- Causal outcome: held-out change in answer accuracy/regret under matched feature patches, with randomized readout controls and a channel-constant LayerNorm gauge control. Match model forwards and token budgets.
- Falsifiers: external artifact absence, checkpoint/source drift, missing positional frequency certificate, missing exact Jacobian export, numeric execution mismatch, near-collision, insufficient curvature margin, unstable chart dependence, or a control explanation with equivalent causal performance.
- No model-quality or compactification-capability claim from a source-only null braid. No 4D embedded-surface or Khovanov-cobordism inference is licensed by this experiment.
