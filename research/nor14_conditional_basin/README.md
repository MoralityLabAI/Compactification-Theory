Protocol registered 15 November 2026. Continues merged NOR-13R [#159](https://github.com/MoralityLabAI/Compactification-Theory/pull/159), NOR-12 [#157](https://github.com/MoralityLabAI/Compactification-Theory/pull/157), and the exact affine top-four order theorem in MathCan [#74](https://github.com/patrickdugan/MathCan/pull/74).

## Mathematical identification limit

The frozen NOR-11 basin probability is a deterministic sigmoid of the original 12-dimensional endpoint hidden state H:

\[
G = 2\,\sigma(w^\top z(H)+b)-1.
\]

For any random proof outcome Y, the sigma-algebra generated by (H,G) equals that generated by H. Therefore

\[
\mathbb P(Y\mid H,G)=\mathbb P(Y\mid H),\qquad I(Y;G\mid H)=0.
\]

Proof: G is measurable in H; conditioning on H already determines G. The usual regular conditional distributions give the equality almost surely, and the conditional KL-divergence is zero. This is an exact information-theoretic statement regardless of how well the logistic head was trained.

It does *not* say that the gate is useless for finite-parameter readouts. It may provide nonlinear features which a constrained linear correction cannot otherwise implement. That is the first NOR-14 hypothesis.

The intermediate recurrence state H_4 is generated from the first four publicly visible source rows. Its basin-head score T = 2 sigmoid(w^T z(H_4)+b)-1 is not *a priori* a function of H_9. H_4 may encode prefix information that H_9 discarded. We test a trajectory feature and a capacity-matched synthetic nonlinear control. A finite held-out gain would show predictive advantage of the chosen feature family in this task. It would not by itself prove positive conditional mutual information.

## Frozen architecture, mathematical constraint and controls

Model: exact preexisting 1,000-parameter RRC-25 GRU under SHA-256

    54f225f2a61c52fee5a740576eaab3bcbc5280a595fc1ac1ac115ec8ac26c41b

The original 16-way task head and original 13-parameter NOR-11 basin probe remain fixed. The train/dev source manifests are reconstructed and checked by NOR-12/13.

Let Z be the 96 x 13 original public training design matrix with rows [z(H_9),1]. For each gate family and each k in 1..12, calculate the 96-vector V_k = G z_k. Construct its least-squares projection onto the numerical column space of Z, using twice-reorthogonalized Gram-Schmidt, without seeing any development or test data:

\[
R_k(h,g)=\frac{g z_k(h)-[z(h),1]\widehat\beta_k}{\max(0.05,\operatorname{RMS}_{\mathrm{train}}(V_k-Z\widehat\beta_k))}.
\]

The finite training moments satisfy Z^T R_k ≈ 0 up to a checked FP64 tolerance. The projection isolates the *nonlinear part outside the training linear span*. Since G is already a function of H_9, this residual is not new information in the information-theoretic sense.

Readout family, with 400 allocated coefficients per model:

\[
s_j=b_j(H_9)+\lambda(u_j^\top z(H_9)+v_j^\top R(H_9,G)+c_j),
\qquad j=1,\ldots,16.
\]

Five active feature families have identical 16 x 25 allocated parameter shapes:

| Arm | Gate source | Purpose |
| --- | --- | --- |
| endpoint_basin | NOR-11 learned head evaluated on H_9 | Main nonlinear basin hypothesis |
| endpoint_shuffled | NOR-11 label-shuffled trained head evaluated on H_9 | Same probe family, negative-label control |
| endpoint_random | Fixed seeded random linear sigmoid of H_9, matched weight norm | Untrained nonlinear endpoint control |
| trajectory_basin | Frozen NOR-11 head evaluated on H_4 | Mid-trajectory state signal |
| trajectory_random | Same random projection applied to H_4 | Mid-trajectory nonlinear control |
| hidden_only | Identically zero interaction features | 400 allocated slots, 208 active coefficients; linear baseline |

The random projection is a deterministic, seed-frozen function of an already available hidden state. It is different from NOR-13's public-input-hash scalar, which could contain additional input information independently of the endpoint representation.

## Training / selection / held-out conditions

- Training: the original 96 source-disjoint NOR-12 cases, with exactly accepted sets of 16 candidate templates from the public degree-192 observed demonstrations. The 1,536 template checks are shared among all fits, with 1,536 label exposures per arm. No future degree-256 coefficients or program identity enter the optimizer.
- Fitting: deterministic full-batch Adam for 150 epochs, step size 0.023 and L2 penalty 0.075. Projection is fitted on training only. The original GRU, original task head, basin head and public verification semantics are unchanged.
- Development: 36 original cases. Each arm's amplitude is selected on this split alone from {0.25, 0.5, 1, 2}. A global development-only selector includes the original scorer as an option.
- Fresh test: four separate 72-case cohorts under seed offset 92517000, different from NOR-12B and NOR-13R. The generator excludes every previously evaluated visible case and all previously evaluated nonlate nine-by-eight model input hashes. Exactly twelve examples from each of six family types occur in each cohort.
- **Primary evaluation**: 240 nonlate held-out examples with one fresh model input hash per example. Main numbers are native degree-256 future-correct outcomes, false accepts, four-check counts, paired gains and losses, and exact two-sided unique-feature sign tests.
- **Secondary evaluation**: all 288 cases, including 48 late_source cases whose nine-by-eight model inputs may alias earlier data. These are case-weighted descriptive totals, and late_source cannot count as 48 distinct model inputs.
- Gate interventions: within the *trained endpoint_basin model* at its development-frozen amplitude, substitute the shuffled endpoint gate, synthetic endpoint gate or early-trajectory gate, or set only the 12 nonlinear residual columns to zero. Every matrix and projection coefficient stays fixed.

The quantitative claim gate is pre-registered: an endpoint-basin-specific advantage requires a positive paired primary gain over **both** the shuffled probe and fixed-random endpoint sigmoid, with familywise error correction for those two comparisons. We report the hidden-only comparison and false-accept costs separately. Trajectory-specific evidence requires a positive primary paired gain over trajectory_random, followed by an independent cohort replication.

No feature-substitution experiment establishes that the basin score is an independent stochastic variable given H_9. Test scores have no interval-certified basin membership interpretation.
