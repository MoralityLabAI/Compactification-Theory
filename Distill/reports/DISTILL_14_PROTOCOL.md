# DISTILL-14: Bounded verified research memory

The DISTILL-13 contrastive history representation improved triplet ranking and shrank equivalent-state latent distances, but action prediction remained weak. This study asks whether it is useful for proposing exact continuation reuse.

## Frozen protocol

Refit the three DISTILL-13 arms (ordered history with/without quotient loss, sorted event multiset with quotient loss) on the same 24 training roots, 18 epochs, two seeds. No evaluation labels are supplied to the encoder. Evaluate 36 new roots (12 each ordinary, shifted, scarce). For each root sample up to 256 distinct literal states uniformly without replacement from the public BFS closure, independent of equivalence labels. Use the first 128 as a nested bank (8,32,128 entries), the remainder as a fixed query stream. This is an off-policy uniform literal-state distribution, not empirical on-policy recurrence.

Compare independent cold exact continuation, literal-key index, exact normalized quotient index, recency, event counts, and all six learned encoders. Approximate rankers see only public stage and history embeddings, try at most two proposals, and use exact normalized quotient key equality for admission. The direct exact index is mandatory and may dominate this finite task. Retrieval remains within one public spec and frozen incumbent policy; no transport across roots. Each bank entry stores exact conditional continuation utility and risk, verified by independent Auditor. All misses run a fresh cold exact solver. Every returned pair must match independent exact values. No approximate equivalence may cancel a certificate.

Declared logical-work accounting includes metered cold solve, key projection, key lookup/compare, memory writes, encoding, scoring, rejection and exact fallback. Bank/query computations and deterministic charges may be replayed across arms for paired accounting; no matched-runtime claim.
