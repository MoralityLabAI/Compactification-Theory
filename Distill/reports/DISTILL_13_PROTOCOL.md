# DISTILL-13: History-state representation learning

DISTILL-11 established exact policy-relative equivalence; DISTILL-12 measured insufficient online payoff. This is a synthetic auxiliary representation experiment, no policy promotion or native DataGoblin update.

## Frozen setup

24 training roots (mixed families/scarcity), six calibration roots (diagnostic only), 12 fresh ordinary, 12 shifted and 12 scarce-credit evaluation roots. Root identity disjoint across splits. Each has 64 weighted worlds and complete reachable-state BFS, one shortest legal public history per literal state. Select at most 48 triplets per root with deterministic root-local sampling. Positive pairs have the same normalized marginal quotient and exact incumbent action, expected priced value and expected false recommendation count. Prefer distinct masks. Negative candidates differ in quotient and at least one exact action/value/risk witness, at the same stage, preferably same saturated-budget/law/anchor/cert prefix. This is a conservative semantic negative, not a claim that the quotient is coarsest. Verify all exported histories and labels independently. Public records contain only observed events and root public spec; root digests are partition identifiers, not model inputs. Export referee labels separately. No actual hidden world or payoff reveal.

24-wide tanh recurrent encoder, initialized from the public spec (prior weights, offsets, budget, costs, family and rewards). Each event gives action and observed outcome only. Output heads predict 32-bin normalized future belief (zero-padded), incumbent action, conditional priced continuation value and risk. Four parameter-matched arms: true history vs deterministically sorted event multiset; each with or without contrastive triplet loss. Sorted control retains exact event counts and recurrence visits but removes ordering. Pair loss = mean squared positive latent distance + max(0, 0.10 - mean squared negative distance), weight 2. No label values at inference. Same 18 epochs, 32 triplets per batch, Adam, fixed seeds 311 and 719; no early stopping or calibration tuning. Report root-macro triplet ranking accuracy, positive/negative distances, posterior total variation, exact incumbent action accuracy and value/risk MAE, individual roots and parameter counts, CPU training time. Pair ranking alone cannot certify state equivalence or justify policy promotion. No provider spend, no native model update, training_admission=false pending review.
